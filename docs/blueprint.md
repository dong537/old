## 目标与边界

主要服务家属，支持按机构名称、区、地址查询235条官方名单，核对地址、电话、备案床位、三项预收费标记与来源。首页、列表、235份档案、收录说明构成完整路径。工商126个主体关联144条机构，仅本机私有预览；名称命中不能证明实际运营关系。86条未明示主体、5条待复核不补造。不上线预约、榜单、后台、价格、空床、处罚等虚构功能。1B保留上门服务方向，须取得可核验名单后再做，不用示例数据占位。

## 架构与 Source of Truth

Next.js 15 / React 19 / TypeScript / Tailwind 3，延续原型技术栈。静态 export，生产无服务器、数据库或密钥；可静态托管 Cloudflare Pages。暂不用数据库是因为当前只有只读快照，无账户或写操作；后续认领必须先设计持久化、权限与审计。

官方owner：广州市民政局2026-09-23的机构基本信息表。`data/raw/family_fields_official.csv`保存九字段；`data/raw/id-map.json`保存原始序号、名称到稳定ID的显式映射。未来名单更新必须审查映射，不能重排URL。导入副本不是实时信息，日期不冒充更新时间。

工商owner：查企GO 2026-11-13查询快照，已有126次留存回包，不再付费请求。原始输入与派生工商文件仅放忽略的`data/private/`。公开再发布许可尚未明确，默认公开构建完全不导入工商模块；`@company-data`在webpack编译时指向公开空实现，仅显式本机开发模式指向私有实现。私有模式禁止production构建、仅绑定127.0.0.1，公开输出扫描私有信用代码和字段；不是CSS隐藏。

Institution（官方机构）、Company（信用代码为键的登记主体）、InstitutionCompanyLink（候选主体名称与企业登记名称的匹配依据、未核实的机构运营关系）分离。候选名与登记名126条完全一致、18条仅中英文括号不同；这些分类不比较养老场所标题与企业名，也不证明企业实际运营该场所。未知保留null；床位为备案数量，不是空床。电话疑似占位原文保留但不拨号；6条手机号格式电话从公开快照暂隐并单独标记；区地址冲突原文保留并提示。

## 模块与接口

`lib/types.ts`定义数据；`lib/import.ts`校验和规范化；`scripts/build-data.ts`读CSV生成静态快照与导入报告；`lib/catalog.ts`提供只读目录；`lib/search.ts`处理筛选分页；`app/`组合页面；`components/`承载呈现和URL状态。禁止内存业务库、运行时第三方请求、静默失败返回空数据。

列表URL：`q`最多80字符，按去空格后的名称/区/地址匹配；`district`只允许11区；`page`从1起，20条一页，按官方序号。非法条件显式提示并可重置；超页码归到最后有效页并提示。客户端读取URL与历史，过滤同一份官方静态目录；档案静态生成，非法ID404。所有日期是北京时间的日期快照，无金额推断。无动态API、权限和响应envelope；机器JSON有schemaVersion、snapshotId、source与institutions。

数据流：官方CSV → 校验/ID映射 → 公开JSON → domain查询 → 静态HTML + 客户端过滤。私有CSV → 校验关联 → 忽略的私有JSON → 仅本机开发工商模块。名单/JSON和HTML随同次构建发布；缓存更新靠重新部署，不做假实时。

保留原型青色#0F6A6E、中文系统字体、1200px容器、按区入口、列表与详情分段。替换虚构数据与演示导航；删除无真实能力的价格、空床、评级、预约、榜单、后台入口。首页主任务“找养老机构”，列表先名称/地区，再地址/床位，档案明确数据来源。无需新品牌、插画或花哨动效。

路由：`/`、`/guangzhou`、`/guangzhou/jigou`、`/guangzhou/jigou/[id]`、`/guangzhou/shangmen`、`/guangzhou/shangmen/[id]`、`/guangzhou/changhuxian`、`/rules`。首次首页查询，回访从URL恢复条件，档案返回保留列表上下文。无账户、提交和破坏性操作；所有导航用链接，GET表单用于搜索。中文为当前唯一语言，文案集中在共享组件和元数据，不预造i18n框架；html lang=zh-CN。
