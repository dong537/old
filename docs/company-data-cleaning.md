# 工商私有资料清洗契约（2026-11-14）

目标：把既有 583 个去重工商主体和其中 564 个“机构/直接照护历史来源相关”主体整理为可重复生成、逐条可追溯的内部资料。用户本轮只要求洗数据，不修改业务页面、公开字段或付费查询。

## 来源与边界

- 工商照面事实的权威是留存的查企GO 原始回包；既有累计 25 字段 CSV 是经原始回包与账本核过的派生输入。本清洗器不改写这两类文件。
- 企业身份以 18 位统一社会信用代码为键；机构、服务点和企业是不同实体。来源名单或查询关键词只说明候选线索，不证明机构运营关系。
- 已审核的机构/直接照护范围 CSV 负责范围标签。不能根据公司名称或经营范围重新猜测范围；范围外/待核 19 个主体仍保留在全量文件。
- 原始字段、来源 URL、证据限制、采集时间及原始回包 SHA 都随清洗结果保留。空字符串在结构化 JSON 中记为 null，原始 CSV 不变；0、未找到、注销、停业和未知不互相替换。

## 输出与数据流

既有累计 CSV + 范围 CSV → 校验列、唯一信用代码、来源 URL、日期、SHA 与范围子集 → 规范状态和显式质量标记 → Git 忽略的 data/private/guangdong-eldercare-source/cleaned/ 下的 JSONL、CSV、待核事项 CSV 与核验 JSON。

每条 JSONL 分离 id、scope、registration（25 项原文值或 null）、provenance（原始关键词、批次、来源 URL 列表、工商采集时间、回包 SHA）和 reviewFlags。状态规范值只供筛选；原始登记状态始终保留。注销只表示查询时登记快照如此；省外登记不表示没有广东服务项目。来源限制含“停业”时仅标记机构状态冲突候选，待核证，不据此更改企业登记状态。

## 失败与验收

输入缺失、列错、重复/非法信用代码、非法 SHA、缺官方线索 URL、日期倒序或范围文件非全量子集，均停止生成。输出写入前完整校验；脚本提供只核验模式。验收 583 条全量、564 条范围内、25 字段逐项不丢、5 个范围内注销、6 个范围内省外登记、来源和 SHA 全有值。测试同时覆盖真实数据和重复代码、空值、冲突提示等边界。

来源批次不同且并非实时；清洗不提供“现存养老机构数”或服务质量结论。进一步把企业连接至具体机构需独立的备案/授权/合同等关系证据和人工审查。

本脚本校验输入表的 SHA 格式、列、日期、信用代码及范围子集，并记录三个输入文件 SHA；并不重新请求查企GO，也不逐份重算原始回包文件的 SHA。后者沿用既有付费查询审计记录。此产物全部在 Git 忽略区，不授权公开再发布。
