# 广东 21 市机构证据管线（私有试点）

本文件记录第十批基线的 v4 清洗。第十二批合并观察与逐字段审查的当前有效版本、输入差异及限制，见 province-batch12-cleaning.md；下文的“当前有效版本”仅相对于第十批基线。

日期：2026-11-14。目标是把第十批来源观察变成可审计的**待审核资料**，供一城试点和后续机构身份审查使用；本阶段不生成全省在营机构目录、不公开工商数据、不调用付费接口。家属端仍以广州 235 条官方快照为唯一公开机构数据。

## 输入、权威与范围

- 来源观察权威输入：`data/private/guangdong-eldercare-source/exports/20261114_batch10/机构名录_逐条来源.csv`，预期 2,129 行、21 市。它保存发布者 URL、公布日、资料期、原始详情及来源文件标识；名称行只是观察，不是机构身份。源文件的字节 SHA-256 记入每次导出清单。官方原件才对“某来源在某时写了什么”负责；CSV 是导入副本。
- 企业登记权威输入：`data/private/guangdong-eldercare-source/research-batch8/paid-registration/exports/累计机构与直接照护工商_25字段.csv`，按统一社会信用代码识别登记主体。查询快照只说明工商登记，不证明机构运营、备案或服务状态；个人字段留在私有输入，不进入本管线候选输出。
- 输出只准写入 `data/private/guangdong-eldercare-source/research-batch11/province-pipeline/` 的版本子目录：清单、来源文档、观察、逐字段声明、名称候选组、同名企业候选关系、状态/来源元数据复核及可能同一实体的待审对。公开站点、静态构建、API 和搜索索引均不读取这些文件。
- 本阶段不从 1,676 个“城市＋名称”键推断 1,676 家独立机构，也不把缺失字段补零或把资料发布日期当资料截止日。跨市电话、价格、空床、预约、质量分数不生成。

## 领域边界与 ID

| 对象 | ID 与职责 | 审核边界 |
| --- | --- | --- |
| SourceDocument | URL＋公布日＋来源文件的内容摘要；保存文件/原件指针及可见哈希 | 同一 URL 不一定是同一版本；哈希缺失要留空 |
| Observation | 原始 CSV 行内容摘要及同内容出现序号；保存输入行号与来源指针 | 跨期同名不覆盖；重导源文件可追溯输入行 |
| Claim | 观察 ID＋原始字段名的摘要；除顶层机构名称外，对详情 JSON 的**全部字段（含空值和来源元数据）**逐键保留原值；74 种字段归类但不丢弃未知字段 | 每个字段携带来源 URL、公布日、原文资料期与行指针；业务字段可有保守规范名，未知字段保留原名，不解释为当前事实 |
| CandidateGroup | 城市＋只去空白、统一括号的名称摘要；为人工审查排序 | 这是候选键，**不是 Institution ID**；同名、异名、迁址与服务点关系均待审 |
| Institution / ServicePoint | 待审核人根据原件和可核证据赋予稳定 ID；区分机构身份与实际服务场所 | 本阶段输出的 institutionId 一律为 null；不得自动合并异名或认定在营 |
| Company / Relationship | 信用代码识别企业；同名仅形成关系候选 | 角色、服务点、证据、起止日期、审核人未确认前，relationshipVerified 恒为 false |
| StatusEvent | 来源中明示的停业/暂停等原文状态信号 | 只进入复核队列；工商存续/注销与机构营业状态各自独立，不自动判当前状态 |
| IdentityPairReview | 同城不同候选名、地址仅去空白后相同，或同一 URL＋来源行指针不同名 | 只给出双方候选键、原始地址/行证据；不能自动合并机构与服务点 |

稳定机构 ID 的后续审核记录至少需要：被审核观察 ID、决定（同一机构/异名/不同机构/服务点）、所依据原件、机构 ID、审核人和审核时间。审核不得用名称相似度直接通过；数据无此记录时不发布 Institution。名称规范化只用于候选排序，不能作为身份证明。

## 接口与数据流

`scripts/province-pipeline.ts` 导出纯函数 `buildProvinceReview(observationCsv, companyCsv)`，严格校验输入表头、必填的城市/机构名/来源 URL、详情 JSON 和信用代码；返回可序列化的私有审核数据。命令行 `./node_modules/.bin/tsx scripts/build-province-review.ts` 只读上述固定输入，完整解析后写入私有版本目录；同一版本已存在时拒绝覆盖。输出 manifest 记录输入 SHA、行数、21 市、候选数及各输出 SHA；Observation 同时无损保存 rawRow 和 rawDetails。没有动态 API、分页或权限接口；文件权限依赖项目 Git 忽略、离线存储和人工访问控制。

数据流：官方原件 → 现有第十批 CSV / 工商回包导出 → 严格校验 → 不作实体判断的观察与逐字段 Claim → 同名/异名、状态、日期及关系复核队列 → 人工审查 → **未来**受控发布索引。数据导出不触发公开构建。顶层与详情中的城市、公布日、资料期均分别保留；日期仅按严格的年/月/日/无时区时刻格式给出规范值及精度，说明性文本为 unparsed，绝不由公布日补资料期。14 条源表把“2026-11-13采集”写在 source_as_of，派生结构保留 asOfRaw、将 asOf 设 null、将 retrievedAt 设 2026-11-13 并送复核；原 CSV 不改。床位原值不变，绝不转换为当前空床；状态原文不转换为当前在营。

## 私有产物与当前核验

当前有效版本：`data/private/guangdong-eldercare-source/research-batch11/province-pipeline/v4-6c20c94161f1-04fc73f9de05/`。JSONL 分开保存 82 个来源文档、2,129 条观察、15,804 条原始字段 Claim、1,676 个名称候选组、279 个**未核实**的同名企业关系候选（工商来源 90 行包含分隔的多个 URL，逐条校验且保留原串）、9 个状态复核候选、253 条来源元数据复核观察和 19 对可能同一机构/服务点待审关系。另有 UTF-8 BOM CSV：`候选机构名称组_待审核.csv`、`待核状态与来源日期.csv`、`可能同一机构或服务点_待审对.csv`、`详情字段清单.csv`。CSV 的“人工确认”均为 false；具体原文和来源见 JSONL。

21 市共 77 个来源 URL。2,129 条观察中顶层资料期缺 1,193 条，来源 SHA 在详情中缺 821 条；公布日 1,001 条带无时区时间、14 条为空；另有 14 条把采集日误置资料期；派生资料期精度为 missing 1,207、day 219、month 275、year 180、unparsed 248。后 248 条是说明性文字，不能转换为精确截止日。详情城市与顶层字面不同 210 条，详情公布日与顶层不同 29 条；它们可能只是“江门/江门市”或不同日期语义，统一进入复核，不自动覆盖。地址待审对采用**仅去空白**比较，包含“广东省 茂名市…/广东省茂名市…”一类源格式差异；19 对仍可能是不同机构共享场所。

产物自检：13 个输出文件 SHA 与 manifest 一致；每条 rawDetails 键均有同观察 ID 的 Claim；候选 CSV 恰有 1,676 行、状态/日期 CSV 262 行、身份待审对 CSV 19 行；全部候选 institutionId 为 null。本轮 v1、v2、v3 均为中间产物，**不可用于后续审核**；只取 v4 与其中 manifest。

重复验收使用只读命令 ./node_modules/.bin/tsx scripts/build-province-review.ts --check。它重新解析固定输入，核对输入 SHA、manifest 各项计数、13 个输出文件 SHA、JSONL/CSV 行数，且与当前输入重新生成的 13 个文件逐字比对，成功后退出 0；默认生成模式仍拒绝覆盖同一版本。行为测试覆盖文件与 SHA 同时被篡改的情形。工商来源有 90 行用“ | ”串接多个链接，v4 中的 companySourceUrls 逐条验证并保留 companySourceUrlRaw 原串。

## 失败、迁移与验收

- 表头或详情 JSON 错误、非法 URL/信用代码、输入行缺关键字段时停止，不用空集合兜底；写输出前完成全部解析与验证。输出由同一批次清单和数据文件构成，失败时保留上一版供回滚。
- 新官方名单进入新批次和新目录，不原地覆写本批输入；旧观察和 ID 保留供差异核对。先以江门等资料期较明确的城市试审，核官方原件的范围、机构/服务点身份及字段资料期，然后逐城扩展。
- 验收：真实 2,129 行全部可追溯到输入行与来源；候选数与第十批核验一致；同名企业关系均未确认；停业等原文状态进入复核；测试覆盖同城同名、跨城同名、地址仅去空白的异名待审对、缺日期、错误置于资料期的采集日、坏数据、企业候选及私有输出边界。运行 `./node_modules/.bin/tsx --test tests/province-pipeline.test.ts` 和 `./node_modules/.bin/tsc --noEmit --incremental false`。
- 仍阻断全省生产发布的事项：21 市尚无一市证实同一时点完整且当前在营；大量资料期缺失；原件/逐字段证据未全量人工审阅；机构—服务点—经营主体关系未审核；持续更新及纠错责任未建立。公开再发布第三方工商字段还须核使用范围。
