# 广东养老来源数据第十二批清洗与核验

日期：2026-11-14（北京时间）。目标是把已存的广东 21 市资料清洗为**可审阅的私有来源观察**。本批不改网站业务、公开目录、部署或第十批原始导出。成功标准是原件可定位、原始值可回看、重复/异类资料隔离、导出可重算。本批尚未确认任何城市同一时点全量、当前在营。

## 权威源、边界与数据流

- 官方网页、附件和图片在公布时所载内容，是“来源写过什么”的权威；本地原件以字节 SHA-256 标识版本。第十批 CSV、本轮三个补充包和香港社署拆分表是导入/转录层，不是当前营业状态权威。工商表用统一社会信用代码识别登记主体；工商存续不等于机构在营。
- scripts/build-batch12-observations.py 核输入、原件 SHA、物理定位和来源类别，生成不可覆盖的私有合并 CSV/manifest；scripts/build-batch12-province-review.ts 复用现有领域函数，生成逐字段 Claim、名称候选组和待审队列。原第十批与第十一批 v4 不覆盖。私有文件由 .gitignore 隔离，公开构建不读取。
- 观察 ID、名称键、企业信用代码和机构 ID 是不同对象。1,770 个城市＋规范名称**候选键不是 1,770 家机构**；290 条同名工商关系候选均未确认。来源 URL、附件 URL、原件路径/SHA、公布日、资料期、抓取时间和物理定位分开存。有效期不能由抓取日或公布日推断。
- 当前只有离线 CSV/JSONL 接口，无公开 API、权限变更、分页或前端状态。缺原件、哈希不符、表头/JSON 错、重复源定位、来源登记不一致时硬失败，不返回空集合。新版本只写新目录；回滚时仅引用旧 manifest，不改旧输入。

## 修正与来源证据

- 香港社署 14 条：research-batch12/hk-swd-cleaning/ 将原名称混入的院舍标签、地址、内地/香港机构、#、@、改名备注拆列。衍生批次使用清洗后的**名称候选**；原名、原详情、脚注及原表 XPath 保留。“2026-11-13采集”改存 retrieved_at，资料期留空。HTML SHA 只作为**配对候选**，未写入权威 source_sha256。@停止接受新申请不代表停业。14 条均与原 HTML 行唯一配对，经独立只读复核；身份与经营关系仍待审。
- 第十批缺逐条 SHA 821 条：research-batch12/provenance-name-audit/v2-6c20c94161f1-3e3fbce0947b/ 在哈希一致候选原件中匹配名称 796 条，珠海图片 25 条文字工具不适用。名称匹配不能证明其余字段，也不能自动确认 URL→原件版本→行的配对，尤其关联附件或本地配对原件。原始哈希缺口**仍为 821**。
- 珠海图片 25 条：research-batch12/zhuhai-image-review/v1-6c20c94161f1-c8ea5ee2a36a/ 记录区块＋区块内序号、图中名称和图片 SHA。25/25 名称与第十批精确一致；这是模型对图的目视自查，非独立人审。床位、星级、地址及逐行哈希未验证，不能按同 URL 批量回填。
- 工商独立清洗层 cleaned/ 保持 583 个去重主体，其中 564 个在机构/直接照护范围；25 个工商字段无损保留。此数不等于机构数，登记状态不等于运营状态。
