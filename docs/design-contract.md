## 第一轮：任务与视觉方案

色彩：主操作青色#0F6A6E、深青#0B5357、来源底#EAF5F5、文字#1F2329、次级#5C626B、背景#F6F7F9。标题使用中文系统字体600/700，正文同族常规以避免字体加载和阅读跳变；数据用系统等宽数字，档案ID使用系统monospace。中文内容不强制外部字体。

```text
首页：来源日期条 → 品牌/导航 → 名称地址搜索 | 资料范围 → 11区入口 → 联系前准备
列表：标题 → 搜索+区筛选 | 名单使用说明
               结果数 | 原表排序
               名称/区 → 地址 → 备案床位/电话 → 档案
               分页
档案：返回原筛选 → 机构名/地址/电话 → 本页目录 | 概况/预收费/工商/来源/核对建议
```

识别点沿用原型“每份资料都能找出处”：来源是检索和档案的结构元素，而不是装饰徽章；不用“已核验”“优质推荐”替代官方名单收录。手机上导航/目录自然换行，档案字段单列；没有hover才能发现的操作。

## 第二轮：针对性自审

删除原型虚构KPI、价格统计、榜单、认领/预约和后台入口。删除无法支撑的自理/失智/长护险筛选。首页将营销承诺改为确有来源的收录范围，不做插画、动画或额外品牌重构；主操作是GET检索。保留卡片作为有边界的搜索/名单/资料段，不做四卡KPI。所有原表缺陷明示，收费“否”不当成免费，工商同名不当成运营已核验。
