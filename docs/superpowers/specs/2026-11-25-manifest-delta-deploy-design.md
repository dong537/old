# 养老预览站按内容差集发布设计（2026-11-25）

## 问题、目标与范围

GitHub Actions run `45434972535` 的构建、归档和下载均成功；同步步骤运行 75 分钟后被超时终止，`rsync`/SSH 仍存活，未执行服务器激活校验，旧站保持在线。上次成功发布的 `rsync --checksum` 对 44,635 个路径逐项处理，21,217 个文件被判变化，实际只发送 34.37 MB，却耗约 33 分钟。稳定 Build ID 已消除纯资料发布的全站 HTML 差异，但不能保证首轮代码发布的全树 rsync 在时限内完成。

目标：每次完整构建和公开扫描后，比较新旧已验证文件清单，仅打包变化的普通文件，删除候选版本中已撤销的文件；激活前仍对候选版本逐文件做完整 SHA-256 校验、原子切换和失败回滚。首次代码版本可能有约 2.1 万个变更文件，传输必须按一个归档进行，避免逐文件跨网交互。预览站继续 `noindex`。本次不改业务数据、页面、采集、发布权限或生产域名。

## 方案与取舍

1. 继续全树 `rsync --checksum`：失败已复现，不能作为主路径。
2. `rsync --files-from`：能减少无变更发布的比较范围，但首次 2.1 万文件仍有大量跨网往返，不能可靠解决此次 75 分钟失败。
3. **采用 SHA 清单差集 + 单一 tar.gz 归档**：服务器把上一版的已验证清单提供给 runner；runner 对比路径和 SHA，打包新增/变化文件；服务器只在硬链接候选树解包并删去已撤销文件，再执行现有全树验证。归档传输次数与文件数无关。压缩和解包仍要读写变化字节，首次代码发布可能花数分钟。

## Source of Truth 与接口

新版本权威输入是 CI 构建出的 `out/` 与其 `eldercare.manifest.sha256`。旧版本权威输入是当前已激活 release 的 `eldercare.manifest.sha256`；老版本尚无该文件时，服务器在当前公开树本地生成一次完整 SHA 清单。该回退仅用于迁移首轮，后续成功发布将清单留在 release 目录外层。最终是否可发布只由新版本清单对候选树的完整 SHA 校验决定，差集只是传输计划，不能绕过验证。

离线 planner 接受 `--previous`、`--next` 两份 GNU `sha256sum` 清单，输出排序后的 `changed.paths.nul`、`removed.paths.nul` 和数量摘要。路径必须是 `./` 起始的安全相对普通文件路径；拒绝重复、转义清单行、绝对路径、空段、`.`/`..`、反斜杠和控制字符。新文件及 SHA 不同的旧路径进入 changed，旧版本独有路径进入 removed。空变化是有效结果，不生成空 tar。

服务器脚本 `prepare` 硬链接复制当前公开树，并输出旧清单；`apply` 仅处理本次 runner 上传的差集归档和删除清单，解包前先解除候选文件的硬链接，不修改当前版本；`activate` 沿用文件数、无软链接、全树 SHA、release marker、旧版未切换等检查，成功后保存新清单并原子切换。构建物上传与 CI 仓库源码的权限不变。

## 数据流、失败与回滚

Git/资料 → 完整静态构建与扫描 → 新 SHA 清单和完整构建 artifact → 服务器旧清单 → runner 校验路径并生成差集 → 仅变化文件归档经 SSH 上传 → 候选树解包/删除 → 服务器全树 SHA 与数量校验 → 原子切换 → HTTP smoke check。临时清单、归档只保存在隔离的 `eldercare-actions/<run>`，公开树不暴露。

旧清单缺失、差集格式非法、归档成员与 changed 清单不一致、SSH/传输中断、解包失败或最终 SHA 不符时，均失败且不激活候选；GitHub cleanup 只删除从未激活的候选。切换后 smoke check 失败则沿现有回滚路径恢复旧 symlink。保留完整日志中 changed/removed 数量、归档字节数、各阶段耗时，不输出私密配置。

## 验证

planner 行为测试覆盖同内容、增加、修改、删除、重复/逃逸路径与清单损坏。发布脚本集成测试在临时 release 根目录使用硬链接候选：变化文件不改旧版、删除只影响候选、失败不切换、最终 SHA 和回滚有效。Linux CI 跑现有 `verify:release` 及发布脚本测试。部署后核对 `release.txt`、首页、目录、详情、文章与纠错页；再对同一 commit 运行一次发布，预期 changed/removed 均为 0、归档传输跳过，记录同步及全树校验真实耗时。
