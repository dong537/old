# 全国官方来源第二批增量设计（2026-11-17）

## 目标和范围

在本地可部署静态站继续增加可逐条追溯的省级官方来源，先接福建省民政厅便民查询表（944 行），再接湖南省民政厅《养老服务机构信息表（2025年版）》（1,768 行）。用户仍要求暂不部署。成功标准是原件哈希、源行覆盖、地区分组、未知与零值、人员字段排除均有可重复校验，且旧重庆/张家港记录 ID 与详情路由不变。官方来源行不等于经核实的当前在营机构。

## Source of Truth 与口径

政府原页及其附件是来源内容的权威；Git 忽略的 `data/private/national-official-source/raw/` 保存原件，`data/raw/national-official-source-manifest.json` 锁定字节数、SHA-256 和行数。`public/data/national-official/` 是从原件生成的脱敏快照，不能覆盖原件或冒充实时数据。福建原页未注明发布日期或资料截至日，两个字段均为 `null`，归档日期只表示本站取得副本的日期；其表混合养老机构和社区照料设施。湖南页面显示发布日期 2026-01-12，正文称金民工程数据截至 2026-01-09；原表混有敬老院、医院、社区等设施。床位 0 是原值，不是未知；空地址才为 `null`。不得发布福建未提供的床位/人数/服务内容或湖南负责人姓名。

## 模块、接口和数据流

离线导入器按来源文件类型解析冻结 HTML/XLSX，逐源验证表头、连续行号、行数、非空名称、地区映射、异常计数、哈希及联系方式，再一次性写最小 JSON。湖南只从原表行政区划列的第二段取地市，其他区县信息不推断；福建以 `fujian/provincewide` 的“全省”组显示，不推断城市。源级 `city: null` 表示省级来源跨城市，索引城市仍有明确 `slug/name`；源级 `publishedAt: null` 表示原文未说明。记录 `address` 可为 `null`，`beds` 可为 `null` 或非负整数；省级来源的每个源行在其所属城市索引出现且仅出现一次。现有索引/详情路径和 schemaVersion 1 保留，记录 ID 继续由源 ID 与原表序号构成。

运行时只从 manifest 白名单取索引和详情，未知值显示“原文未说明”或“原表未提供”；不把归档日替代发布日期，不把 0 渲染为缺失，不显示联系人、电话或原始 XLSX。公开扫描器验证日期可空规则、字段白名单、分块/地区/来源行覆盖、无个人信息及原件不进入 `out/`。页面 URL 筛选与返回逻辑不变；正式来源链接仍指向政府网页。

## 失败、回滚、验证

原件变化、表头/行数漂移、无法解释的地市、缺失名称、意外联系方式、来源行重复、公开分块不一致时停止构建并报错，不用空集合兜底。独立输入清单和快照版本使旧构建可回滚；本轮只生成本地新 `out/`，不切换腾讯云版本。先补行为/负例测试，再检查导入 `--check`、Python/TypeScript 测试、类型检查、完整静态构建与隔离扫描；在真实浏览器验证福建/湖南地区、检索、详情、来源和返回、未知日期/地址与 0 床位，以及五个视口和错误恢复。原生 200% 缩放若不可测，继续明确保留。

辽宁省民政厅另有 2,375 条 XLSX，但页面标有“未经授权禁止转载”；只可暂作私有完整性参照，未经授权不进入公开投影。其他省份待核原件与使用条件后另加，不能因候选主体库覆盖 31 省而宣称全国官方机构名录已完整。
