# 达州开放数据 30 行增量设计（2026-11-17）

## 目标、范围与成功标准

在本地跨省官方来源目录中追加达州市民政局经达州公共数据开放网公开的 30 条匿名预览行，保留原顺序、名称、地址、床位和源级日期。只增加一份来源观察，不认定达州市全量、当前在营或与登记主体的运营关系；本轮不部署。成功标准是原件/许可锁定、30 行零丢失、人员字段不外泄、列表和详情可查、既有 ID 不变。

## Source of Truth 与使用边界

目录 https://www.dazhoudata.cn/oportal/catalog/8295bd1137254b6699c69992f30de94d 标注来源部门为达州市民政局、无条件开放、目录发布时间 2024-01-10、最后更新 2026-08-14、数据量 179。目录内许可允许自由利用/传播/分享无条件开放数据，要求成果注明来源并定期反馈利用情况。匿名预览接口的冻结响应只返回 30 行，不能用目录元数据 179 补充未取得的行。目录原页与预览 JSON 均留在 Git 忽略的 data/private/national-official-source/raw/；公开 JSON 是脱敏投影，非原件或实时接口。许可回访与更新责任仍需在正式发布前落实。

## 模块、接口与数据流

scripts/dazhou_official_rows.py 验证目录页 SHA、许可文字、元数据和预览 JSON SHA、30 行、字段集合、地区、名称/地址及床位类型。scripts/build-national-official.py 以冻结源锁调用解析器，按现有 schemaVersion 1 生成 sichuan/dazhou 索引与详情块；仅投影 name、address、beds，原始负责人姓名、联系字段和其他非必要属性完全排除。scripts/check-public-output.ts 只对白名单中的精确达州目录 URL 放行，仍拒绝同形恶意域名。前端沿用现有 province、city、q、page 与详情返回 URL，原始来源页为出站核查入口。

## 失败、回滚与验证

目录页许可或元数据变化、JSON 哈希/结构/行数漂移、地区越界、空名称地址、联系方式混入、床位非整数、公开路径或来源行覆盖不一致时拒绝生成。空床位原值保留 null，0 保留 0；1 条区县空值不推断所在区。通过定向 Python/TypeScript 行为测试、完整本地构建及公开隔离扫描后，在真实浏览器检查达州 30 条的地区选择、详情与来源、返回和异常恢复。保持旧静态包可回滚，不触及腾讯云当前版本。
