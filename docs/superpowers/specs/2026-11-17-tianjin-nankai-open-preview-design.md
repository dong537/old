# 天津南开区开放预览增量设计（2026-11-17）

## 目标与范围

为本地 /quanguo/laiyuan/ 增加天津市第一个可追溯官方来源：开放平台《南开区养老机构》实际匿名预览的 20 行。成功标准是只出现这 20 行且名称、地址可回到原页面逐行核对；不声称取得目录标称的 42 行，不扩大为天津全市机构名录，不显示电话、不部署。现有全国官方来源 schemaVersion 1、路由、省市筛选、既有记录 ID 均不变。

## Source of Truth、授权与数据流

权威来源为 https://open.data.tj.gov.cn/sjjk/45e4998327f34ddd8dab66770999e631.htm 的内联预览 JSON；匿名页面已冻结为 Git 忽略的 data/private/national-official-source/raw/tianjin-nankai-preview-20261117.html。天津开放平台 https://open.data.tj.gov.cn/xgxx/wzsm/index.htm 的网站声明明确无条件开放资源可自由利用、传播、分享，成果须注明“天津市信息资源统一开放平台”；该声明同样私有冻结并以 SHA-256 验证。天津市民政局网站单独的限制性声明只适用其自身站点，民政局图片名单不在本增量中。

数据流：开放平台匿名 HTML 与许可页 → 私有冻结原件 → 离线解析器校验哈希、许可、来源元数据、预览字段、20 行、原序号列表、名称地址和联系方式 → source manifest 锁定源页哈希/字节/20 行 → 既有全国官方 builder 输出天津/南开索引、详情块及 manifest → 既有 UI 按省市筛选、详情和原站链接。公开 JSON 是脱敏展示快照，不能冒充实时数据；原页的 totalCount=42 是未取得的元数据，不进公开数量。

## 接口、单位与状态

来源 ID 采用 tj-nankai-20220411，省级 slug 为 tianjin，城市 slug 为 tianjin，省市显示分别为“天津市”和“天津”；scope 明确仅南开区 2022 年开放预览 20 行。publishedAt 取数据页的 2022-04-02，asOf 为 null，因为页面未说明资料截至日；2022-04-11 仅记为目录更新时间。每条 rowNumber 是冻结预览 list 中从 1 开始的数组位次，公开 ID 由来源 ID 和该位次构成；源自平台的“序号”是字符串排序的 1、10—19、2、20—27，不能将其误认成连续 1—20 的原始表序号。公开地址来自“地址”，名称来自“名称”；床位、入住人数、员工人数、服务内容均为 null；“联系电话”整列不进入公开模型。

## 失败、回滚与验证

原页或许可页 SHA/字节变化，许可文本不再包含自由利用/传播/分享与注明来源，数据页开放状态/来源部门/日期变化，预览键/列序/20 行/原序号变化，名称或地址为空或含联系方式，均停止生成，保留旧投影并给出错误，不以默认零或空集合补位。source lock、公开 manifest、索引/详情和隔离扫描须互相吻合，且源 HTML 和电话不能进入 public/out。回滚为恢复上一版 source lock、builder、投影与文档；不改既有广东或登记主体来源。测试先写负例并验证失败，再实现解析器、builder 与扫描白名单；运行定向 Python/TypeScript 测试、builder --check、typecheck 和 git diff --check。完整 build、归档、部署由主任务统一验收，本增量不执行。
