# 本地跨省官方来源增量：泰安、攀枝花与达州区县（2026-11-17）

## 目标与边界

家属在现有 `/quanguo/laiyuan/` 按省、市、名称查找可追溯的官方**来源观察记录**，进入详情核对原文。成功标准是每条公开行都有固定原件、原始行号、地区、来源链接和明确覆盖说明，且可在本机静态导出及浏览器完成检索—详情—返回。此次不建立机构实体、当前营业或空床结论，不接预约、工商匹配，也不部署到腾讯云。

## Source of Truth 与数据流

- 山东泰安：泰安市民政局开放目录的 2025-07-24 CSV 93 行。2026-08-01 CSV 仅 10 行，全部是旧版的完全一致子集；缩减原因未知，因此 93 行仅作历史来源观察。两个原件与目录/许可页面冻结在 `data/private/national-official-source/raw/`。公开白名单为名称和地址，原件的区划代码、开办时间不发布。
- 四川攀枝花：市民政局开放目录的匿名完整预览 21 行，范围明确只含床位数不少于 100 张的机构。冻结目录和预览 JSON；公开白名单为名称、来源床位数，地址未知。原件中的区域、性质只用于解析审计，本次公开 schema 不包含这些列。
- 四川达州：宣汉、万源、大竹、开江四个区县目录的匿名预览分别实际取得 27、21、21、14 行。四份目录各自声明无条件开放；其 API 一律返回机械性的 `recordsTotal=30`，只能以实际预览长度和目录数据量核对行数。仅公开名称与地址，联系人、电话、负责人、登记机关及其他原表字段留在私有原件。与既有达州市级 30 行精确名称/地址不重叠，但不能据此认定为新增独立机构；四个来源仍归入现有达州城市索引，逐源保留单独标题、链接和区县边界。
- 来源锁在 `data/raw/national-official-source-manifest.json`，包括文件名、字节、SHA-256、原始行数。独立解析器验证目录许可、原件结构、行数、排序与隐私字段；`scripts/build-national-official.py` 将通过验证的行投影为 manifest、省市索引和详情块。前端仅消费这个既有静态接口，URL 搜索状态属于客户端而非权威数据。
- 来源发布日不是逐家资料期。床位值不是可用空床；缺失地址为 `null`，不得填造。企查查登记主体库与官方来源行依旧是不同对象。

## 接口、失败与验证

公开 JSON 延续 v1 schema：`id/sourceId/rowNumber/name/address/beds`，详情另有 `residentCount/staffCount/services`，未知取 `null`；现有 `province,city,q,page` 过滤与 20 条分页不变。原件哈希、目录许可、表头、行数、范围、联系人模式、来源 URL 或跨快照关联变化时，离线构建/公开扫描失败，不回退到空集合或假值。

达州四区县的 `rowNumber` 明确表示冻结匿名预览的 1 起位次，不能冒充部分原表中的不连续 `XH` 序号；来源范围文案必须逐项说明这一口径。万源两条同址名称保留为各自来源观察，不自动合并。

Python 行为测试覆盖冻结原件、较新子集、许可漂移、敏感字段及首末行；TypeScript 扫描测试覆盖两个精确来源 URL、范围文案和私有原件隔离。最终运行 `NEXT_PUBLIC_ELDERCARE_BASE_PATH=/eldercare` 的 `npm.cmd run verify:local-release`，再以真实浏览器自测两市列表、搜索、详情、来源和返回。回滚只需恢复前一版本地静态归档；不得用旧归档覆盖用户工作树。

龙口跨年 92 行存在同年同名但状态、地址及部分信用代码冲突，当前来源行 schema 没有年份与冲突展示能力，暂不接入；见 `docs/research/subagents/longkou-duplication-audit-2026-11-17.md`。正式发布仍需持续遵守各平台来源署名、反馈、备案或下线责任及完成公众纠错入口。
