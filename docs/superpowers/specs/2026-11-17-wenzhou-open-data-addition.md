# 温州养老院历史来源接入（2026-11-17）

## 目标与边界

给全国官方来源目录补充温州市公共数据开放平台《温州养老院信息》的 196 条可定位历史来源行，使家属能按浙江省、温州市检索并查看原文与来源。成功标准是 196 行在本地静态站可检索，原始行号、名称、行政区域及原表总床位可追溯，且不把它们称为 2026 年在营机构或浙江全省全量。本次不新增预约、价格、空床、运营主体确认、在线账号或正式部署。

## Source of Truth 与数据流

权威原件为已冻结的官方数据集元数据页、许可页及 ZIP/XLS，保存在 Git 忽略的 `data/private/national-official-source/raw/`。`scripts/wenzhou_6724_official_rows.py` 锁定原件字节、SHA-256、表头、196 个物理行号、11 个行政区域分布及许可义务；`data/raw/national-official-source-manifest.json` 记录公开投影所依赖的版本。原件经离线解析器和字段白名单进入 `scripts/build-national-official.py`，再生成 `public/data/national-official/` 的 manifest、温州索引及详情块；浏览器只读静态 JSON。来源更新须新建快照、复核差异，不直接覆盖历史行。

开放平台标记发布时间 2021-11-09、数据集更新时间 2022-08-26，未给逐家资料截至日；公开 `publishedAt` 和 `asOf` 不得伪装为当前运营状态。源表 196 行中有重名行，来源行不自动合并为机构。原表总床位与普通床位加护理床位有 10 行不一致，保留原表总床位并注明其仅为历史来源值，不推算空床。法定代表人、自由文本简介及其他未核字段不进入公开投影；源表没有可核地址时为 `null`。

## 接口与失败处理

沿用全国官方来源 v1 接口：每个 source 保留 ID、省市、范围、标题、URL、发布日期、资料期、原件哈希和行数；城市索引按省市与稳定行 ID 映射详情块，详情包含名称、地址可空、床位可空、来源行号。仅浙江省温州市增加城市组，不修改其他地区的记录语义与现有 ID。同省同名企查查线索关联只是候选，重建时仍标身份未核实。

原件/许可哈希、表头、行数、行政区域、床位格式或输出白名单漂移时导入失败，不返回空列表或假成功；个人字段与联系方式不得进入 `public/` 或 `out/`。回滚是从来源清单移除本组并重新生成官方快照及候选关联，保留原件和审计记录。

## 验证与发布条件

验证专属解析器及生成器正反例、首中末行与 196 行覆盖、来源哈希、同省关联重算、公开产物扫描、类型检查、完整测试、静态构建，以及真实浏览器的温州检索、详情、来源、返回和移动视口。正式发布前，按许可注明“温州市公共数据开放平台”，完成应用备案、持续展示协议约束，并设立平台下线时的撤除责任；本轮仅更新本地可部署产物。
