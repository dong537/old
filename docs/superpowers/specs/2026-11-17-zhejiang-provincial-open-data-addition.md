# 浙江省开放平台养老机构数据增量设计（2026-11-17）

## 目标与边界

服务于本地全国官方逐名来源目录的家属查询。将浙江省数据开放平台《养老机构信息》原件中**实际取得的 1,147 条来源行**作为冻结输入，先排除 263 条完全重复的额外行，再排除去重后 210 条泛名行，公开 **674 条可按名称识别的来源观察记录**，保留非连续的原始行号与原序，按文件内五个地市分组。成功标准是原件、许可和字段均可离线校验，输出不泄露私人信息，用户可回访原目录并清楚看到覆盖与质量限制。仅本地接入，不部署；不把来源行数当机构数，不推断各家当前营业、空床、全省完整覆盖或个体资料截至日，不自动与企查查主体合并。

## 实际文件范围与质量

CSV 为 UTF-8 BOM，表头五个业务列（所属地市、机构名称、机构地址、总床位数、更新时间）和第六个全空尾列；表头后确有 1,147 行。行数按地市为宁波 520、台州 321、杭州 217、衢州 52、绍兴 37；**其余浙江地市未出现在原件**，故目录标签“全省”不可直接变成产品覆盖声明。全部行更新时间同为 2026-08-21 09:31:12，公开 asOf=null，scope 只解释“文件内统一更新时间”，不标为逐家当日有效。

审计发现 263 条与另一来源行五字段完全相同的额外行，去重后 884 行；按“地市+名称”仅有 672 个不同键，但此键既不保证主体唯一，也不构成“672 家”。台州原件 212 行名称只有“养老机构”，去重后 210 行，公开投影排除并在 scope 说明，不展示为可识别机构。最终公开 674 行，五市分布为宁波 260、台州 108、杭州 217、衢州 52、绍兴 37。原件 55 行机构地址为空、148 行总床位数为“-”，解析为 null；公开记录仍有 49 行地址为空、0 行床位未知。没有数字 0 行，但解析器保留 0 为 0。不可用补零或同名合并掩盖未知。床位是原文件值，不是当前空床。

## 数据流与接口

官方目录及许可/下载 JSON → 私有冻结原件 → scripts/zhejiang_official_rows.py 校验哈希、许可、开放状态、数据集关联、表头、1,147 行和五市分布 → 仅返回 row_number/name/city_name/city_slug/address/beds → 去重并排除泛名 → 现有 builder 和 manifest 接入 schemaVersion 1 静态 JSON。公开记录 ID 为 zj-prov-20260902-{原始 row_number:04d}，保留非连续源行号及可追溯性；无运行时外部请求。锁定清单 rowCount=1,147，公开 manifest 来源 rowCount=674、总计 6,992；scanner 仅对浙江允许原行号最大 1,147，其余来源仍逐行全覆盖。来源 scope 清楚列五市、重复/泛名筛除、空值和未知资料有效期；注明浙江省数据开放平台及 2026-11-17 下载日期，声明该平台协议约束。publishedAt 不从目录创建时间猜测；asOf=null。姓名、手机号、信用代码、负责人等本原件均无对应列；只允许解析器输出字段，不把旧受限省级目录或杭州数据拼接。

## 失败模式、验证与回滚

原件/目录/许可哈希漂移、开放属性变化、字段新增、行数/地市/重复结构变化、意外联系方式进入名称或地址时构建失败；不得以元数据 1,147 或五行预览替代原件。定向测试覆盖原件完整性、缺失值与重复、许可和下载链、哈希/表头/隐私负例；builder/scanner 检查首中末行、五市输出、公开目录聚合及非连续源行号，公开产物不得含私有原件或个人列。若数据下线或授权义务未履行，回滚为移除新增来源并重建本地静态输出，不影响既有地区数据；正式发布前补备案、下载日期展示、协议约束声明和下线监控/撤除责任人，并做浏览器来源链接与错误恢复核验。
