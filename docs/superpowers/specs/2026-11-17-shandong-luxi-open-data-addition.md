# 山东菏泽鲁西新区开放数据增量设计（2026-11-17）

## 目标、用户、范围与成功标准

给家属使用的本地全国官方来源目录增加菏泽鲁西新区公开的逐名来源记录。只投影 2025-06-27 CSV 的 23 个原始行，保留来源顺序和行号、名称与地址，用户可按山东省／菏泽市检索并回访官方目录。页面须明确这是**鲁西新区局部历史快照**，不证明机构目前在营，也不代表菏泽市或山东省全量。本轮不部署、不与工商主体自动合并、不公开个人信息或原 CSV。

## 数据流与接口

原始下载与目录页 → 私有原件锁 → scripts/shandong_luxi_official_rows.py 验证哈希、目录许可和两版关系 → scripts/build-national-official.py 投影至现有 schemaVersion 1 的 shandong/heze 索引与详情块 → 现有 /quanguo/laiyuan 搜索、详情和来源链接。公开记录沿用 id/sourceId/rowNumber/name/address/beds/residentCount/staffCount/services；床位、人数、服务均为未知 null。只读取“机构名称”和“机构地址”作为展示内容；“统一社会信用代码”“法定代表人”“法人性质”“机构类别”“运营方式”不进入公开投影。源级 scope 明示新区边界与两版矛盾。

来源 manifest 锁定 2025 原件的文件名、字节、哈希及 23 行；解析器额外验证 2026 原件为旧版五行的同字段子集，并验证目录页许可文案。外部系统没有运行时依赖或缓存更新；发布数据是离线快照。现有索引 URL 参数、分页、错误恢复和静态站权限模式保持不变。

## 失败模式、回滚及验收

来源哈希、表头、行数、版本子集、空名称或地址、联系方式混入公开字段、目录许可或来源 URL 白名单漂移时构建失败，不输出部分新数据。测试覆盖真实 23 行、前末行、私密列排除及上述负例；公开隔离扫描继续禁止 CSV 原件与敏感字段。检查生成前后快照和 23 个行号完整；父任务统一完成静态构建、浏览器主流程、公开文件扫描与回滚包核对。本地回滚为撤回新增来源锁和解析器、重新生成旧快照；不切换线上版本。许可要求的定期反馈责任须在正式部署前落实。
