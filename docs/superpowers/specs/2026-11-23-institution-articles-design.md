# 机构文章首版设计（2026-11-23）

## 目标与边界

面向查找养老机构的家属，发布一篇以已留存资料为依据的中文机构解读文章；读者可从机构档案进入文章、从文章回到同一档案，并逐段核对来源。成功标准是资料时点和未知项清楚、无体验或当前服务的虚构结论、移动端可读，且同一机构可关联多篇文章。首版不做企业投稿、在线审核、图片、评分或预约。

## 来源与数据流

机构的主键和原始字段以 mcaCatalogLoader 的公开机构快照为准，文章不是机构原始字段的替代品。文章的发布源是仓库内逐篇结构化 JSON；按机构 mcaId 建一对多关系。每篇文章保留来源 URL、资料观察时间、发表和更新日期，正文段落显式关联来源 ID。内容从受审 JSON 经构建期读取、校验、静态路由输出到 HTML；编辑稿不放在公开目录，也不从浏览器直接写入。机构快照或来源网页更新，不会自动改写文章事实；必须复核文章后再发布新版。

## 模块与接口

- lib/institution-articles.ts 负责验证文章 schema、发布状态、来源、机构外键和唯一 slug，并提供 listPublishedInstitutionArticles(institutionId)、getPublishedInstitutionArticle(institutionId, slug)、listPublishedArticlePaths()。缺失返回 null 或空列表；损坏和错误关联使构建失败，不吞错。
- content/institution-articles/*.json 每文件一篇，包含 schemaVersion、slug、institutionId、status、标题、摘要、署名标签、发布日期、更新日期、资料时点、段落和来源；段落引用来源 ID。仅 published 进入页面。
- /quanguo/pingtai/[id]/wenzhang/[slug]/ 由 Next 静态导出预生成；机构详情的“相关文章”区只在有文章时出现。文章页有明确的机构返回链接、来源与资料时点，并复用现有中文色彩、容器和可访问控件。
- 当前 output: export 不能提供生产 POST。未来企业材料上传需独立鉴权、文件检查、审核记录及发布存储；审核通过后的内容才进入同一发布 DTO。此处“接口准备”指已实现的只读内容契约和明确的投稿边界，不虚构可用后台。

## 页面与内容约定

首屏先说明文章回答什么、它依据哪一时点的资料，以及不能证明当前在营、空床、收费或照护质量。正文按读者核对任务排列：已记录的事实、可从中判断的事项、需要向机构核实的事项。来源列表链接原页。作者只能写真实的站点资料整理署名，不能冒充探访者或有资质审核人。文章不提供医疗建议，不机械生成 FAQ 或评分结构化数据。

简化线框：面包屑 → 标题/摘要/来源时点 → 核对提示 → 正文与引用 → 来源列表 → 返回机构。机构页：现有资料段落 → 相关文章列表（标题/摘要/日期） → 来源。文章列表在窄屏单列，链接最小触控高度 44px；320、375、768、1024、1440px 和 200% 缩放核对溢出、焦点与阅读顺序。

## 失败、验证与回滚

机构外键无详情、重复 slug、无可用来源、正文引用不存在、非 HTTPS 来源、日期格式错误或稿件仍含待补占位符均阻止发布。文章路由 404 不暴露未发布稿；机构没有文章时保留原档案流程。测试覆盖多篇排序、外键、未发布隔离和渲染链接；运行 typecheck、测试、构建及现有公开输出扫描，最后用真实浏览器走机构→文章→来源/返回的键盘与移动端路径。回滚时删除文章 JSON 和路由、撤销机构页入口；机构数据及既有路由不迁移。

## 设计依据

站点现有机构详情以来源快照为核心，文章延续同一语义色与资料边界；eeat-article-writer 仅采用真实素材、逐项证据和发布自检流程，其英文 SEO 与无凭据作者/审稿人模板不适用于本站。第三方页面布局调研另记于本任务验收记录；页面是家属的核对辅助，不按商业养老站的推荐卡片和转化文案写。
