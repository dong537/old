# 广东全省公开来源目录实施方案

> 本方案承接用户要求上线全省目录，沿用现有广州真实目录与 /eldercare/ 静态发布路径。执行时逐项核对，保留未提交的用户改动。

**目标与用户：** 家属可按广东 21 市检索养老相关官方来源中的逐条名称记录，打开原始来源核对；每条记录的时间与证据类型可见。成功标准为 21 市可检索、记录可追源、广州 235 条档案不回退、构建隔离检查通过、线上主要路径及旁站正常。

**范围：** 发布“广东养老相关公开来源记录”索引。它是跨期资料线索，不是同一时点全量在营机构名册；不把同名行、企业主体、服务设施与独立机构自动等同。广州 235 条单来源档案仍由既有页面承载。不开放预约、认领、价格、空床或第三方工商详情。

**数据权威与流向：** 民政等公开原件为事实来源；第十五批冻结清洗包是离线证据副本。私有包中的 cumulative-roster-candidates.csv 共 2,429 条、21 市，混有名录、历史、专项、星级、企业和设施记录。公开主目录仅选每市一份已取到的官方逐名来源，以城市＋来源 URL＋证据类型精确白名单投影，预估 781 条来源行；不能按文件或名称模糊放行。公开投影只允许城市、原文名称、证据类型、来源 URL、来源发布日期、原文明示的资料期、原来源状态警示和版本内记录编号。原始 details、source_file、联系人、电话、床位、工商照面与内部路径不得发布。用户限定的省开放平台 XLSX 仅用于查漏，不加入本次详情。公开 JSON 是网站构建时的冻结副本，来源更新需离线重新投影、复核、版本化发布；页面不请求查企 GO 或其他付费 API。

**语义与接口：** 公开对象是 SourceRecord，不是 Institution。ID 仅定位冻结版本的一条来源观察，不是机构 ID；同城同名记录不自动合并。来源发布日期与资料截止期分列，缺失显示“原文未说明”，不填今天。城市筛选、关键词与页码使用 URL 参数 city、q、page；无效参数回退到全部记录并给可见提示。详情页只陈述该条原始来源及未知项，外部链接使用安全的 http/https URL。所有数量称“来源记录”，绝不称“在营机构数”。

**模块边界：** scripts 的投影器负责固定输入、字段白名单、ID、格式与校验；lib 的省级模型与搜索负责类型、关键词、城市和分页；app/guangdong 负责静态路由；components 负责列表与筛选。广州 Catalog、列表、对比与档案不改数据语义。全站导航与搜索按当前路由分流。静态 JSON 不包含私有字段，公开输出扫描在构建后运行。

**状态与失败：** 旧来源无逐行 SHA、部分资料期或发布日期空缺、链接可能失效；页面明确标为待核来源线索，不推断当前营业与可联系状态。广州海珠、揭阳普宁、茂名高州、梅州蕉岭、清远清城、韶关曲江、阳江阳春等来源只覆盖区县，任何城市行数都不能称全市机构数。链接缺失或非法则投影失败；原始资料的发布日期/资料期缺失可以显示未知。发现负面经营状态的记录不可呈现为可选服务；索引无联系或预约操作。投影字段新增、逐市记录数异常、21 市不齐、输出泄漏、构建或线上 smoke 失败时停止切换版本。

**部署与回滚：** 用现有 Next.js 静态导出，在 NEXT_PUBLIC_ELDERCARE_BASE_PATH=/eldercare 下构建；只上传 out/ 到 /var/www/eldercare/releases/ 新版本，核验后原子切换 current。Nginx 仍隔离 /eldercare/，保留 noindex；不得动根站与 /tk-license/。失败时将 current 指回先前版本，不改旧内容。无公众纠错渠道和正式域名，发布后仍作为带 noindex 的验收站。

**验证：** 投影器行为测试覆盖白名单、重复、缺日期、非法 URL、敏感字段和固定记录数；搜索测试覆盖多词、城市、页码与空结果。运行 typecheck、全部测试、带前缀的生产构建、公开输出扫描；浏览器自测 320/375/768/1440 宽度、键盘、筛选、详情、返回及来源出口；线上检查状态码、链接、noindex、原有广州/根站/旁站。
