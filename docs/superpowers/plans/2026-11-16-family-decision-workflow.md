# 家属筛选与探访决策补齐（2026-11-16）

## 目标、范围与验收

面向寻找广州养老机构的家属，完成“筛出可进一步联系的机构 → 对比已有资料 → 带着问题联系、探访”的只读闭环。成功标准：三项官方预收费标记可分别按“是／否／原表未提供”筛选，组合条件及最多 3 家对比可在 URL、前进后退与档案返回时保持；对比结果能打印成逐家核对单，且不会把未确认事项伪装成平台事实。移动端档案应尽早提供联系电话，全站搜索框应显示当前 URL 中的关键词。

本轮只改既有家属目录流程及必要的测试、样式和说明。预约、认领、报错提交、账户、当前空床和收费金额仍须在合作、权限、处理责任及逐家资料具备后另行设计；不以原型内存状态或虚构数据上线。

## Source of Truth 与模块边界

- 广州机构及三项预收费标记来自既有官方名单快照，由 `data/raw/family_fields_official.csv` 经既有构建脚本生成公开 JSON，再由 `lib/catalog.ts` 读取；本轮不改输入和数据映射。字段 true、false、null 分别表示原表“是”、“否”、“未提供”，不表示收费金额、免费或当前政策。
- `lib/search.ts` 负责查询规范化、三态过滤、分面计数、页码和无效参数提示。允许的 URL 值是 yes、no、unknown，空值表示全部；无效值恢复全部并显示问题。
- `components/DirectoryView.tsx` 从 URL 读取筛选/对比状态并编排结果；`DirectoryFilters.tsx` 只呈现筛选与可访问链接。`lib/compare.ts` 仅保留白名单查询参数作为对比和档案返回上下文。URL 是临时选择的唯一状态源，不引入账户或浏览器持久化。
- `ComparisonView.tsx` 从同一公开快照展示 2–3 家对比和打印核对单。表单留白由家属离线填写，网站不收集、存储或回传老人资料。
- 既有静态 Next.js 站继续导出至 `/eldercare/`；不新增 API、服务端写路径或生产密钥。

## 界面任务路径与证据

首屏仍以原型 `dist(1)` 的列表位置与站点风格为视觉依据：关键词、区域、现有官方字段筛选、结果数、机构卡片、对比出口。新筛选行遵守原有 chip、URL 导航和已选条件清除方式；尚无证据的月费、长护险、医疗、等级和可信度筛选保持禁用。对比页增加打印动作，打印版按机构分块预填名称、地址、可公开电话、备案床位、预收费标记及资料来源/日期，空床、实际收费、服务和合同主体留作核对问题。

同类任务核对（2026-11-16）：[Medicare 选择养老院指南](https://www.medicare.gov/providers-services/original-medicare/nursing-homes/choosing)原页明确查找、比较、探访、选择，并建议每家一份探访清单；[CQC 查找养老院说明](https://www.cqc.org.uk/care-services/find-care-home)原页说明机构详情可见报告、运营者和联系方式。本项目采用“对比后逐家核对”任务顺序，不复制英美评级或检查结论。上海养老服务平台此次只读到 JavaScript 页面壳，不能据此推断其实际结果布局。

## 交互、边界与验证

- URL 接口：`/guangzhou/jigou/?q=...&district=...&advanceFee=yes|no|unknown&deposit=yes|no|unknown&membershipFee=yes|no|unknown&page=...&compare=...`。调整筛选重置页码，保留其他筛选及对比选择；每个筛选选项的计数在其他条件下计算，当前维度不限制自身计数。
- 对比链接仍仅接受已知且去重的至多 3 个 ID；`from` 仅可返回广州机构目录，并按白名单保留查询上下文。返回地址允许至多 2,048 个编码字符，以覆盖 80 个四字节 Unicode 搜索字符；超长地址拒绝。空结果与非法参数给出明确恢复路径。
- 打印按钮只在至少 2 家可对比时出现；打印版隔离普通导航和交互控件。电话未公开或待核实时按既有展示规则呈现，不填假号码。
- 测试：三态、组合、未知值、分面计数、URL 保留、清空和打印内容；执行 TypeScript 类型检查、全套测试、静态构建及公开文件隔离检查。浏览器自测覆盖列表→筛选→对比→档案→返回、键盘、320/375/768/1024/1440px、200% 缩放和打印预览；记录未覆盖项，不把自测称为用户验证。

真实失败模式：误把 false 当免费、null 当否，筛选后丢失对比上下文，打印遗漏来源日期或展示受限电话。回退只需撤销本轮业务组件和测试的增量改动；原有官方快照及旧路由不迁移。
