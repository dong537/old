# 待补地区的外部官方核验入口（2026-11-18）

## 目标与边界

家属在全国官方来源覆盖页看到“本站待补”的省级地区时，应能继续到该地区的官方逐名资料或全国政务查询入口核对，同时保留本站现有机构线索入口。成功标准：31 地区覆盖计数与现有快照完全不变；18 个待补地区各有可辨别的外部官方核验路径；局部、历史、参评和需登录等范围在链接旁明确说明。外部入口不等于本站已取得或有权再展示的逐家记录，不宣称目前在营、全省全量、空床或商业再用许可。本阶段不复制外站行数据、不申请账户、不增加公开来源行、不部署。

## Source of Truth 与数据流

- 地区与覆盖计数仍只由企查查机构线索 manifest、省外官方来源 manifest 和广东来源快照决定。外部链接是另一类人工策展的核验入口，不能参与行数、机构数或实体匹配计算。
- 精确 URL、发布单位、标题、地理/时点范围及 2026-11-18 访问结果来自 docs/research/subagents/national-pointers-*.md 和前轮冻结来源研究；新增可追踪的链接配置只保留用户可见的最小字段。资料变化须人工复核后更新，不能从页面标题推断现行状态。
- 数据流：官方页/政府数据目录 → 人工核验与研究记录 → 静态链接配置 → OfficialCoverageView 的待补地区行 → 用户自愿打开外部站点。不存在外部运行时抓取、缓存、用户数据回传或后台权限写入。

## 模块、界面与接口

- 链接配置按省级地区原名精确映射；每项包含标题、HTTPS URL、范围说明和核验日期。只保留实际确认属于政府/民政部门的逐名入口；找不到合格地区入口时使用已在站内列出的国家政务服务养老机构查询。外部站点若需验证码或本机访问受限，文案如实告知。
- OfficialCoverageView 只做展示编排：已接入官方来源的地区维持原有内部入口；待补地区并列呈现“查看本站机构线索”和“到官方页面核对”两个独立链接，避免嵌套链接。外链新窗口打开，显式外链符号和屏幕阅读器提示；焦点与换行沿用现有样式。
- 无新 API、数据迁移、价格、权限或状态写入。链接的访问失败由外站决定，本站不显示假成功；通用国家查询为恢复出口。地区名和 URL 不匹配、非 HTTPS、重复地区或资料范围缺失时，构建/测试拒绝配置。

## 实施与验证

1. 先写行为测试：江西待补地区提供赣州局部名单的外链与范围，其他未配置地区使用国家查询；内部线索链接和覆盖计数不变。运行测试确认 RED。
2. 增加精确映射与最小 UI 改动，按两组研究报告逐项填入可核的地区入口；对证据不足的地区保留明确的国家查询回退，不放旧站或第三方商业页面。
3. 运行定向测试、类型检查、完整本地发布检查、公开文件隔离扫描；浏览器核查首屏/覆盖区、江西及至少一个回退省份的链接、键盘/焦点、320/375/768/1440px、/eldercare basePath、控制台与返回路径。无公开记录新增，官方来源 manifest 应仍为 7,719 行加广东 781 行。

回滚只撤销链接配置、待补地区显示和对应测试；原始快照、机构详情 URL 及所有既有用户数据保持不变。
