> **For agentic workers:** 按独立文件边界并行实现，由根代理整合、构建与真实浏览器复验。

**Goal:** 以用户明确指定的 `C:/Users/Lenovo/Desktop/search/dist(1)` 为视觉唯一依据，将正式真实目录的首页、检索、档案、来源与对比恢复为同一套页面体系。

**Tech Stack:** 既有 Next.js 15.5.29 / React 19.1.10 / TypeScript / Tailwind 3 / 静态导出。

## 测试与验收

相关行为变更先写能失败的公共接口测试，视觉本身用改前/改后与参考截图对照，不写锁定class实现细节的大snapshot。类型/行为执行真实安装的 `C:/Program Files/nodejs/npm.cmd run typecheck`、`npm.cmd test`，统一构建执行 `npm.cmd run build`。完整测试已知历史失败为 `tests/province-pipeline.test.ts:161` 私有CSV 596与固定564行不一致，不改无关数据迎合断言。

浏览器分别打开3100参考和3210最终out，在相同1440×1000与375×900下比较首页、列表、官方未认领型档案、方法论；对比页核对同套视觉。测header检索、chips区筛选、分页、空态、勾选3家/拒绝4家、快速勾选与立即提交、对比/档案往返、3→2→1→0键盘移除、原生表格局部横滚、无console错误。全套敏感字段扫描必须通过。外部官方来源此前403如仍受限如实保留，不替换为假来源。

回滚：仅按本任务的文件级diff恢复；已有未提交目录功能与全省数据不宽泛回退。当前大量用户改动不做自动清理、reset或全量提交。生产仍为静态out交付，未授权域名发布，不部署本机Node预览。
