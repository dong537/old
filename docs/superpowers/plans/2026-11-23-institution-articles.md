# 机构文章首版实施计划

**目标：** 用一篇有来源的机构资料解读完成可发布文章页，并让同一机构可关联多篇文章。

**架构：** 构建期从逐篇 JSON 读取受审文章，按 MCA ID 与机构关联，静态生成文章详情页；机构页只读显示文章摘要。当前静态导出不提供投稿写接口。

**技术栈：** Next.js 15 静态导出、React 19、TypeScript、现有 Tailwind tokens、Node test/tsx。

## 全局约束

- 只改相关文章功能；不动现有机构快照字段、生产部署或采集器。
- 来源和采集时点必须可见；未知不能写成零、否或当前承诺。
- 不制造探访、专业审核、实时状态和未获证实的服务体验。
- 保留用户未提交改动；按项目现有脚本验证。
