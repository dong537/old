# 民政部平台机构全字段接入方案（执行中，2026-11-18）

## 目标、范围与成功标准

家属在本站按省市、机构性质、医疗条件、收住能力、费用区间和星级查找机构，进入档案核对逐字段来源。取得民政部全国养老服务信息平台当前公开列表及逐家详情的完整可复现快照，清洗后与现有企查查线索、地方官方来源和登记主体候选做实体关联。成功须同时满足：分页无遗漏且去重键稳定、详情覆盖率可审计、字段含义及资料时间明确、冲突保留双方原值和来源、公开字段再展示边界可核、静态构建与真实浏览器任务通过。

本阶段不把接口 `total` 直接当作全国当前在营机构数，不把官网月费/床位当作实时价格/空床，不通过同名直接合并场所，不将电话或联系人等字段未经核查写入公开包，也不以假数据补齐缺失。

## Source of Truth 与数据流

- 外部原件：官网 `queryOrganizationDataList` 和单条详情接口响应，只保存在 Git 忽略的 `data/private/mca-*`。采集器记录请求口径、时间、HTTP/业务码、页号、服务端 `total/size`、响应哈希、失败和重试；支持断点续跑。页面签名只作为官网公开客户端请求格式，不放入公开构建。
- 冻结快照：完整列表与详情校验后生成版本化、非联系字段的规范化数据和字段字典。官方平台 ID 是该来源内部 ID；它不自动替代本站既有来源行 ID、统一社会信用代码或场所身份。原始响应不直接作为 UI API。
- 实体匹配：同信用代码且同地点/行政区或有直接来源证据才自动建立已核关联；仅同名、地址相似或主体同名仍标候选。重复、分支、同院多经营主体和一主体多场所保留独立记录并给复核队列。
- 冲突策略：对已确认同一场所的同一语义字段，本站展示优先采用该官网快照；保留地方表、企查查原值、资料期和来源 URL 供比较。官网字段为空/未知不覆盖已有非空事实；不同单位、设施与法人主体字段不互相覆盖。官网页面说明信息由机构提供，仍应标示来源时点与需联系机构确认。
- 公开展示：现有 Next 静态导出及 `/eldercare/` basePath 不变；经许可与隐私核对后，离线脚本把公开字段写入分省市索引/详情分块和 manifest，客户端只读这些版本化 JSON。没有完整验收前不切换当前“找养老机构”主入口或部署。

## 模块与接口

- `scripts/` 中的 MCA 采集 Adapter 负责 HTTP/签名/限速/重试/断点；规范化构建器负责字段映射、单位、空值和来源元数据，不在 React 组件内清洗。
- `lib/` 中的机构快照类型、严格校验及搜索函数承载稳定 ID、筛选、排序、分页和错误语义。建议新增 `/quanguo/jigou/` 作为官网来源目录；现有 `/quanguo/cankao/` 保留为企查查来源线索，`/quanguo/laiyuan/` 保留地方官方来源。三者以明确标签互链，不混计总数。
- 列表查询 URL 使用可复制的 `province/city/q/type/medical/care/cost/grade/page` 等参数；具体代码值以已冻结字典和实际字段为准。无效参数给可恢复反馈，零结果与读取失败区别呈现。机构详情按官网 ID 查询本地分块；显示每个字段值、空值、来源和资料时间。

## 真实失败模式与发布门槛

- 2026-11-18 实测列表签名 POST 返回业务码 0。页面默认 `ahae0635=1` 是“仅显示补贴参与机构”，此口径全国 `total=35,644`、广东 1,243；取消该筛选后全国 `total=39,384`、广东 1,422。请求 `size=100` 服务端仍给 10 条，未筛选全量约需 3,939 页；逐家两类详情还需更多请求。这些总量尚未经全页去重和类型复核。直连及浏览器有超时/403/502，代理路径和请求签名可能变化。采集器必须限速、退避，保留失败页，禁止将部分成功标为完整。
- 完整性门禁：请求页数覆盖 1..末页，所有页有效且页长/总量一致，官方 ID 非空且重复有审计，按省份抽样及首中末页复核；详情请求成功数/缺口、字段空值率、类型分布、敏感字段扫描和冲突清单可审计。若分页顺序不稳定，优先按地区分区重抓并比较 ID 集，不做静默去重。
- 代码门禁：规范化/字段优先级/匹配/过滤的行为测试，`npm run typecheck`、相关 Python 测试、`npm run verify:local-release`、公开包隔离扫描。浏览器以 320/375/768/1024/1440px、键盘、加载/空/错/恢复、目录→详情→返回和筛选 URL 做开发者自测。
- 回滚：保留旧 manifest/静态归档和服务器旧 release；新版本仅在数据与 UI 门禁通过后原子切换 `/var/www/eldercare/current`。本轮不修改线上数据或 Nginx。
