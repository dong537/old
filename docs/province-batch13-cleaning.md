# 第十三批：已有养老来源数据的分层清洗

任务建立：2026-11-14；本轮清洗归档与离线验收：2026-11-15（Asia/Shanghai）。用户最新范围为“先不做业务方面的改动，先把这些数据全部洗出来”。本任务以已保存原件和有效清洗基线为输入；先收束现有包，新增来源发现不等于本轮清洗完成。不改网站、公开目录、发布和收费查询。原抓取与研究核查日仍按原日志保留，不因归档日期更新而改写。

## 目标和验收

1. 第十二批2,348条基线观察和583个工商主体保持只读，校验有效产物及哈希。
2. 第十三批各分区原件的可提取行分为名录观察、历史快照、专项子集、重复发布候选及状态事件，保留原名、原字段、原件SHA和物理定位。
3. 统一八列来源协议与来源路径；产生不可覆盖的新清洗版本、21市清洗/缺口矩阵和待处理原件清单。未知值不填零、不猜实体身份或当前状态。
4. 明示统计截止日与网页发布时间、附件名日期、星级评定年度及事件日期分离；不把日期标签当作精确统计截止日。
5. 原件哈希、字段位置、分类、日期迁移、重复和错误反例可复算。尚不能提取/未核验的数据逐份列出，不宣称全部已洗完。

## 权威源与接口

- 官方网页/附件原字节负责“该版本写过什么”；SHA和物理定位固定版本。来源观察不是机构实体；工商主体以信用代码去重，但登记存续不证明机构运营。
- 各分区来源包是提取层；有效第十二批合并CSV是历史导入基线。统一清洗包仅做私有审核，原包字段逐项保留，规范字段与原始字段分开。
- 脚本输入为本地CSV/JSON/HTML/XLS/PDF/图片，输出为Git忽略目录内CSV/JSONL/manifest；不增加数据库、API或运行时依赖。新增HTML解析依赖固定为lxml==6.0.4。
- 统一列：city,institution_name,source_url,source_published_at,source_as_of,source_file,evidence_type,details。source_file规范为相对data/private/guangdong-eldercare-source的路径；source_as_of仅接纳已明示统计截止日。日期标签另存details，原包原值保留。
- 不按名称自动合并实体。精确城市/规范名称/URL键仅用于重复观察核对；同名匹配只生成待核候选。

## 数据流、失败与回滚

旧基线＋分区提取包 → 离线原件与定位核验 → 分类观察/逐字段证据/日期迁移记录 → 新版累计名录来源观察及私有审核管道 → 覆盖与剩余问题报告。

缺原件、SHA不符、表头漂移、列值错位、源定位重复或归档字节变化均硬失败。访问受限原件与扫描件不以空集合伪造成功。新版本写独立路径；旧版不覆盖。回滚只引用旧manifest，不撤回用户其他文件。
