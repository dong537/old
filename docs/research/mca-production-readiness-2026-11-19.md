## 响应原件与字段审查

旧版 93 份列表响应和 36 份详情中的两个端点响应，合计 **165 份端点 wrapper**，都有声明的 `responseSha256`，但均无 `rawBodyBase64`：**0 份能由原始 HTTP 字节重新计算校验，165 份标记 `rawBodyUnavailable`**。审计器另计算 41 份 manifest、93 份列表页、36 份详情文件的本地文件集哈希，结果为 `9f767b3e3132ea3cbffdea2c66a3e0fd83f2fa85c315cf33570f000109104b74`。它只固定本次审计输入的**本地文件字节**，不可冒充原 HTTP 响应哈希或官方签名。今后新采集批次须保存原响应字节，逐端点校验哈希且比对解析 JSON。

在有效样本中观察到 **148 条嵌套字段路径**（含数组/对象父路径，不等于 148 个业务字段）。既有私有预览实际投影 25 条路径；另有 31 条非空路径尚未解释、6 条已有拟映射但未投影的非空路径、3 条联系人/电话受限路径及 70 条嵌套隐私待审路径。逐路径清单在私有审计 JSON 中；这些计数有重叠层级，不应相加成字段总数。星级原键 `list.ahde8404` 已根据本地官网脚本的“机构星级”标签列为**未投影候选**，并非生产展示已核准。受限路径包括 `list.ahae0012`、`orgBaseDetail.ahae2572`、`orgBaseDetail.ahae2573`。

同 ID 列表与基本详情的 `axbe0004` 原值在 **36/36 个已配对样本**中不同：列表为代码 `1`、对应 `axbe0004Name=养老机构`，基本详情的 `axbe0004` 却是标签“养老机构”、`axbe0004Name=null`。这证明当前样本的**代码/标签承载位置不同**，不能以详情文本覆盖列表代码；单凭原值不同也不能断言机构类型冲突。跨类别语义仍待详情页面证据确认，参见[字段语义核对](./mca-field-semantics-2026-11-19.md)。已观察的名称、地址、区域码以及列表与养老详情床位字段在这 36 个配对中未发现非空原值冲突，但样本过小，不能推出其他地区无冲突。列表页跨切片重复 ID 的所选标量字段也未见不同原值；这仅是当前缓存的字面比较，不证明时效。备案床位、平台列示床位、注册主体地址、机构服务地址及企业登记状态仍分别保留定义和来源。

## 逐字段公开再展示依据

既有[官网来源与再展示核查](./mca-source-reuse-2026-11-18.md)记录：列表页提示“以下信息由养老机构提供，详情请与机构联系”，网站页脚标示民政部版权所有；当时未找到允许第三方**批量复制、改写及再发布逐家字段**的明确许可。该核查覆盖入口和相关脚本，不能当作全站法律结论；`robots.txt` 返回应用 HTML 外壳，也不构成允许批量再展示的证据。用户认为官方平台数据可信，解决的是来源优先级偏好，**不自动解决逐字段再展示权限，也不保证机构填报数据实时准确**。本次没有新增许可文件或逐字段授权证据。

因此原始名称、地址、床位、收费、评分、联系人、电话、图片、介绍和嵌套对象均不能因为“公开页面可看”就整批写入本网站。尤其联系人、个人手机号、自由文本和图片需要单独做个人信息/版权审查。可以先保持私有核验与对账；面向用户的保守替代是仅在核实来源链接的有效性与使用边界后，展示**原站机构详情深链、平台机构 ID、来源平台、实际访问时点和“请至原站核实最新信息”**，不复制逐家详情字段、不宣称在营或空床。深链仍须逐条可打开，访问时点不是资料更新日期，且该替代方案不能代替正式的再展示依据审查。
