# 全国平台地区树：独立轮次续采（2026-11-19）

此脚本只续采官网地区节点树，不下载机构列表或详情，也不发布网站数据。原始响应、日志、状态和清单均保存在 Git 忽略的 `data/private/mca-institutions-2026-11-18/`。地区节点数量不能当作养老机构数量。

## 入口和触发条件

`scripts/run-mca-tree-resume.py` 每次只执行一轮；没有自动重试或定时器。需先确认上一轮已结束，且上一轮状态与当前 `area-tree-20261119/manifest.json` 的审计时间对应；上一轮必须是采集器退出 0、无 429、无业务/解析错误、仅因 20 次请求预算耗尽而留下待访问父节点。站点冷却期、正在运行的采集器、已有/重复轮次 ID、状态或 manifest 缺失/不一致时拒绝联网。采集器自身还用全站独占锁、滚动每小时 60 次预算及单线程 60–70 秒请求间隔。

完成上述本地核对后，在项目根目录执行一轮，例如：

```powershell
python scripts/run-mca-tree-resume.py --previous-run-id tree-20261119-a --run-id tree-20261119-b
```

下一轮须使用新的 `--run-id`，并以刚完成的轮次作为 `--previous-run-id`。不要复用 `tree-20261119-a` 等已有 ID，也不要在当前轮次结束前启动下一轮。脚本会先写独立的 `batch-runs/<run-id>.status.json` 运行标记，结束后更新状态；日志在同目录的 `<run-id>.log`。状态列出开始/结束 UTC 时间、请求次数、缓存响应前后数及增量、待访问父节点前后数、429 和错误。进程中断后留存 `phase=running`，后续续采会拒绝；需人工核验缓存和站点状态，不能把这种异常当作纯预算中断。

退出码 `0` 仅表示地区树走完且无错误；`1` 是本轮已运行但树未完或采集出错；`2` 是预检拒绝且未调用采集器。退出码 `1` 只有在状态及 manifest 都再次明确显示纯预算中断时，才可人工发起新轮次。任何 429、业务错误、损坏缓存或状态不明均停止并保留证据；不得自动循环请求。即使地区树完成，也不代表全国机构名录/详情已采完，更不构成同一时点的全国完整快照。

离线验证：`python -m unittest tests.test_mca_tree_resume -v` 与 `python -m py_compile scripts/run-mca-tree-resume.py`。

## 串行无人值守控制器

地区树节点可能需要多轮。`scripts/run-mca-tree-auto-resume.py` 在**现有采集进程结束且本地结果核对通过后**可串行调用上述一次性入口；它本身不启动定时任务，也不会与已运行的树采集并行。启动示例：

```powershell
python scripts/run-mca-tree-auto-resume.py --previous-run-id tree-20261119-a --batch-prefix tree-20261119-auto --max-batches 32
```

控制器使用独立锁阻止第二个控制器启动。每轮 ID 为 `tree-20261119-auto-001`、`-002` 等；每次重启重读连续状态链，防止覆盖或跳号。每批最多 20 次站点请求、间隔 60–70 秒；全站滚动小时 60 次账本由原采集器强制执行，控制器在账本满额时等待到下一窗口。官网 429、接口/校验错误、站点锁冲突、状态/manifest 不一致、子进程超时或中断都停止，不自动重试。默认最多 32 批，达到上限仍未完成则退出，需人工复核后另行决定是否提高上限。

需要优雅停止时，在项目根目录执行 `New-Item -ItemType File data/private/mca-institutions-2026-11-18/batch-runs/tree-20261119-auto.stop`；控制器在下一批开始前退出，当前批完成后才会检查。重新启动前人工核验最后的状态和 manifest，再删除该 stop 文件。Ctrl+C 会立即中断控制器，可能使子批次留下 `phase=running`；此时不得直接重启，先人工核验缓存与站点状态。状态脚本退出码：`0` 树完成，`2` 错误停止，`3` stop 文件停止，`4` 批次数上限，`130` Ctrl+C。

全国地区树通常有数百个需请求的父节点，在当前单线程间隔和共享 60 次/小时预算下，完成可能需要至少数小时，实际进度取决于响应、断点和官网状态；这**不包含**后续机构列表及逐家详情。控制器离线测试为 `python -m unittest tests.test_mca_tree_auto_resume -v`。
