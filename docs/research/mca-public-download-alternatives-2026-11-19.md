# 全国机构级公开下载渠道复核（2026-11-19）

## 问题与结论边界

目标是寻找不需申请、可直接下载、由官方发布、覆盖全国且逐家列出养老机构的 CSV/XLSX 原件，以减少对全国养老服务信息平台分页接口的负载。此次只查公开网页、搜索索引和既有本地研究，没有访问 yanglao.mca.gov.cn 的 API，也没有启动新的采集任务。**本轮未证实存在满足全部条件的官方整表下载地址**；这是检索范围内的阴性结果，不证明该资源绝对不存在。

## 检索证据与局限

2026-11-19 用搜索索引检索 site:mca.gov.cn filetype:xlsx 养老机构、site:yanglao.mca.gov.cn xlsx、全国养老服务信息平台 下载 机构名录、全国养老机构信息 CSV 下载 民政部。360 搜索返回旧版查询页、地方名录和商业数据文章，未返回可核验的民政部全国机构级 XLSX/CSV 原件。Bing 对同组查询返回大量无关结果；Brave 搜索调用返回 fetch failed，不能把它们当作完整检索。旧版政务服务链接的 404 是一次网络观测，未来可能变化。所有判断仅对应本轮检索范围和日期。

商业“全国机构数据”下载页、企业名录、统计公报或星级名单均不能替代当期、全量、逐家、可追溯的官方机构记录。继续采用现有站点级独占锁、滚动请求预算和断点续采；先完成地区树与稳定分页核对，再处理详情及字段清洗。任何来源若找到可直接下载原件，先记录发布主体、源页、下载 URL、资料期、文件哈希、行数、字段、开放条件，再与平台 ID 做保守对账，不直接覆盖已有来源。
