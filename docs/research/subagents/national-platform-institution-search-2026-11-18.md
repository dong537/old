# 国家级养老机构查询入口逐家检索核查（2026-11-18）

## 本轮目标与样本

对《养老竞品网站调研表.xlsx》的 O01 全国养老服务信息平台、O02 全国养老机构信息查询，尝试以本站已有官方来源记录中的“云浮市福利院”“云浮市三房养老院”按全名定位逐家结果。两名称均见本站 `public/data/guangdong-source-records.v1.json`，原始官方来源为云浮市民政局 2026-03-09 页面；选它们仅用于测试查询能否得到可核对结果，**不是**断言两站应当收录。

## O01 全国养老服务信息平台

- 入口：`https://yanglao.mca.gov.cn/#/index/institutionList`。2026-11-18 匿名 GET 网站根目录返回 HTTP 200、11,891 字节的 Vue 应用 HTML；路由在公开脚本中确有 `institutionList`（“机构养老”）组件。静态 HTML 不含机构明细。
- 本轮站内浏览器不可用（浏览器访问宿主返回 `The browser access host is unavailable`）；获取该列表组件脚本两次分别出现 TLS/代理握手超时和读取超时。此前项目核查记录列表/地区接口出现 HTTP 502。因此，本轮**未完成站内按姓名提交检索，也未取得可核对的逐家结果或下载文件**。
- 对两名称作站点限定搜索，没有形成可验证的该平台详情 URL；搜索索引未命中不是本站未收录的证据。当前可确认的是公开入口和“机构养老”路由，而非具体机构字段、结果数、实时状态、API 可用性或第三方再展示许可。

## O02 国家政务服务平台“全国养老机构信息查询”

- 入口：`https://app.gjzwfw.gov.cn/jmopen/webapp/html5/qgyljgxxcx/index.html`。2026-11-18 匿名 GET 返回 HTTP 200、约 7 KB HTML，标题为“[民政部]全国养老机构信息查询”。
- 静态页面实见地区选择、机构名称输入、图形验证码和“立刻查询”；“查询结果”表头为地区、机构名称、统一社会信用代码、地址、床位数。页面带验证码；本轮没有完成验证码、没有提交两条姓名查询，也没有得到逐家结果。未见静态页面提供 XLSX/CSV 批量导出。
- 表头只证明页面设计了这些字段，不能证明任何具体机构记录或当前在营情况；床位数也不能当作实时空床。没有取得批量采集和逐字段第三方再展示许可。

## 可复核结论

两个入口都可作用户到原站的人工核验路径，但本轮**实际取得的机构级匹配：0 条**，含义是“未取得可验证结果”，不是“已查明样本不在国家平台”。不把上述静态表头或搜索索引转为本站机构事实，不绕验证码、不推测接口。后续若站内访问恢复，可由人工以相同名称查询，逐条记录查询日期、结果页定位、代码与地址，再与云浮原始来源做身份核对；如需批量纳入本站，另核开放协议及再展示范围。
