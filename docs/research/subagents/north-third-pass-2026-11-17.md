# 北方六省区养老机构来源补查（2026-11-17）

本轮仅研究内蒙古、辽宁、吉林、黑龙江、山西、河北的官方逐名来源。公开投影与共享生成器未修改；新增可发布机构来源行 **0**。目录元数据、搜索结果、掩码预览及登记主体候选均不算已核实机构。

## 新线索：哈尔滨开放平台不可据此导入

- 哈尔滨政府数据开放平台搜索中有[道里区养老机构基本信息](https://data.harbin.gov.cn/oportal/catalog/5751fa7972ae4d26b49eecd48cafafca)与[哈尔滨市老年公寓基本信息（道里区）](https://data.harbin.gov.cn/oportal/catalog/616b10414af9439ebfc76c8ed506305b)。目录均标无条件开放、21 条；前者显示 2024-10-15 更新，后者显示 2024-10-16 更新，提供方字段为“大数据中心”。这是两个来源，不代表道里区有 42 家不同机构。
- 页面所附数据使用许可称无条件开放数据可自由利用、传播和分享，形成数据产品应标明来源并定期反馈利用情况；但这不解决**可用逐名原件**问题。匿名 XLS 预览各显示 21 行，两个来源的机构名称均为 **21/21 星号遮蔽**，第二份还含法人和电话列。不能用残缺名称构建可检索档案，亦不能用地址反推、拼接私有数据来绕开遮蔽。下载区的 `download_check=1` 表示需走平台登录流程；未测试规避登录的文件请求。
- 更关键的是，[该站 robots.txt](https://data.harbin.gov.cn/robots.txt) 于本轮核对返回 HTTP 200，内容对 `User-agent: *` 设置 `Disallow: /`。发现后立即停止抓取，并删除本轮临时保存的四份目录/预览 HTML（逐一核对不存在）；**未留下私有原件，也未接入公开或本地候选数据**。此前已作页面访问属本轮操作失误，后续若需使用应联系平台取得明确的访问方式或授权。
