## 公开投影与许可

- 官方 schema 只有所属地市、机构名称、机构地址、总床位数、更新时间五个开放字段；前四列标 L2（低敏感）、时间列标 L1（不敏感）。最小公开投影只取经核验的五列，加来源标识、实际下载日期及物理行号。末尾空列、完整目录/API 响应、内部 ID、userSecret 等不得进入公开 JSON。名称/地址的邮箱、11 位手机号、18 位身份证号模式扫描均为零命中；自由文本仍须维持白名单和抽查，不能宣称绝无个人信息。
- 冻结详情的 agreement 字段为《浙江省数据开放平台数据开放授权许可使用协议》：允许现阶段免费、非排他获取及复制、发布、利用、传播、分享；使用成果须标注“浙江省数据开放平台”和平台下载日期。基于数据开发应用须及时通过网站备案；服务中须声明平台协议约束，并让再授权用户接受；不得侵害隐私、歪曲篡改。源数据下线后须停止保存/使用并调整服务；违反义务会自动终止许可，须删除数据及停止服务。平台不保证数据完整、准确、及时或服务连续。
- 协议未明确写“公开前审批”作为前置条件，也未单列商业用途；不能声称已备案、获专项商业授权或能无限期保留。正式公开前应核对当时协议、实际下载日期、备案路径与下线处理机制。本审计依据 2026-11-17 冻结的官方 API 协议文本；搜索接口未取得实时数据集详情，未独立证明以后条款不变。
