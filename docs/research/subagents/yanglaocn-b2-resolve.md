# 养老信息网 B2 本地宽松候选比对（2026-11-18）

## 范围与输入

本任务只读 data/private/yanglaocn-20261118/combined-b2-final/reconciled-candidates.json（170 个详情 URL；输入 SHA-256 见 b2-resolve-b2-final/summary.json），以及已有全国机构线索 41,955 行、全国官方来源 7,719 行、广东官方来源 781 行。全程离线，不请求养老信息网或其他站点，不写公开数据、不部署。先前 b2-resolve/ 是 167 URL 基线的试算，不用于本报告；本报告以 b2-resolve-b2-final/ 为唯一结果。

本轮目标为 115 个“同省名称未精确命中”URL 提供人工复核线索。50 个地域未知 URL 不借机构名称猜省份，也不做同省匹配；5 个已有同省精确名称候选不重复宽松匹配。源站链接名与搜索索引地域必须由同一条合格观察提供，不能把不同观察的名称和地域拼接。搜索索引仍是检索证据，不是来源正文。

## 方法与边界

- 先按已观察省份限制来源行；名称经 NFKC、空白与标点规范化，仅允许具辨识度的共同后缀、完整名称包含或明确标记“原/曾用名/又名/别名”的括号别名形成候选。共同后缀还要核对前段地域词，排除仅共享“养老服务有限公司”“中心敬老院”等通用尾词及不同街道/区县前缀。
- 地址只采用已保存的详情正文结构化地址；检索摘要中的地址不当作正文地址。本次地址规则及明确括号别名规则均未新增候选对，11 对实际均为共同辨识后缀。
- 每对保留候选 ID、原 URL、来源快照类别和来源行 ID、观察 ID、原始名称、城市/地址、匹配规则、分数和冲突。分数 84 是本轮规则的排序权重，不是身份概率。同名或近名、同省、同市、甚至官方名录命中均不代表同一主体或当前在营。
- 把城市不一致标为 city-mismatch；观察名中的区县与现有来源名称/地址文字冲突时标为 district-mismatch。这些是文本差异提示，不自行裁决行政区划变迁或资料时效。
