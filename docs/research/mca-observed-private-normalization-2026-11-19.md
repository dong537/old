# MCA 现代来源链私有规范化入口（2026-11-19）

## 目标与边界

在地区树、首屏、分页和双端点详情采集仍持续运行时，先建立可复算的**私有**规范化入口。输入仅为 `national-area-*`、可选 `national-level4-*` 的已保存官网响应与队列；输出仍位于同一 Git 忽略的私有根目录。成功标准是已观察队列逐 ID 形成已知非联系字段的来源证据，不把旧试采、未完成批次或未知字段混入。它不是全国完整性、在营状态、登记主体、资料时效或批量公开许可的证明。

## Source of Truth 与数据流

原始 HTTP 字节、请求参数、逐页 JSON、队列、双端点 checkpoint 和批次状态是源。先调用 audit-mca-field-production-gate.py 对现代来源链做离线校验；仅当基础详情阶段完整且所有存在的现代阶段均 verified、输入在审计期间不变时，才生成私有文件。覆盖异常与重复观察保留在记录中，不因私有清洗而丢失，也不能据此宣称全国完整。若有四级 overlay 种子且其中有代码，四级增量详情阶段也必须完整通过。生成后重跑同一来源审计并比较输入摘要，再原子替换目标；失败则删除临时文件，保留既有产物。

以 `queue.json` 的有序 `items` 或四级 `mergedItems` 为记录顺序；列表来源逐一回读 `sourcePages[].pagePath` 的 ID 行，详情优先读取增量目录中新 ID 的双端点文件，其余读取基础详情目录。每条证据保留原始值或明确的 `missing/null/empty/whitespace/numeric_zero/string_zero/populated` 状态、端点、私有相对路径、页面编号/地区代码（列表）、请求与响应时刻、保存文件及 HTTP 原文 SHA-256。重复观察和同义字段冲突保留多条证据，不以较晚采集时间或详情端点自动择值。

## 当前字段白名单

## 接口、失败与验收

生产 CLI 入口为 scripts/normalize-mca-observed-private.py，固定读取项目 data/private/mca-institutions-2026-11-18/，不接受 --root 或任意输出目录。测试可直接调用函数并注入临时来源根。目标为该私有根下 national-observed-normalized-private.v1.json。文件写入 schemaVersion=1、publishable=false、nationalComplete=false、snapshotVerified=false、源队列摘要、输入集合摘要、覆盖异常、记录数及逐字段证据。输出未知、缺失与零时不补默认事实。

缺队列/详情、来源批次未核验、页或详情原件漂移、无效字段类型、覆盖标记内部矛盾、四级增量缺失均拒绝输出。来源链可重验但列表覆盖异常时，私有产物保留异常与原行，由独立发布门禁阻断。行为测试用真实格式的离线 fixture 覆盖完整基础链、零/null/缺键、来源 SHA/时刻、重复/冲突、total 漂移标记、四级复用及任意路径 CLI 拒绝；无官网请求。正式生产发布仍需独立全国覆盖、字段定义、隐私/再展示、页面与部署门禁，不得据此私有产物单独放行。
