# 民政部平台机构数据接入：字段与实体映射（2026-11-18）

## 目标、范围与当前证据

目标是把全国养老服务信息平台机构记录作为**独立、可追溯的来源快照**接入本站，在同一场所经确认关联后优先展示该平台同义字段；保留既有来源原值、日期和冲突提示。家属可按实际取得的省市、机构类型、床位、费用和服务条件筛选。当前仅有少量脱敏列表样本、筛选字典和**单家**两接口详情样本；全量与逐字段语义尚未验收，不能把接口总数当本站机构数。

- 官方页面：`https://yanglao.mca.gov.cn/?#/index/institutionList`；列表 POST `/ylxxptapi/ylfwpt/ylfw/queryOrganizationDataList`。2026-11-18 带页面请求头返回业务码 0；用户已确认需全量采集与逐字段核对。
- **两种查询口径不能混用**：不传 `ahae0635` 时接口报告全国 `total=39,384`、广东 `total=1,422`；传 `ahae0635=1`（页面默认仅显示补贴参与机构）时分别为 `35,644`、`1,243`。均只是请求当时接口返回的记录数，不是去重、当前在营或同一时点的法定养老机构总数。
- 样本存于 Git 忽略的 `data/private/mca-institution-list-retry-2026-11-18/`；请求 `size=100` 被服务端裁成 `data.size=10`，10 条返回；请求 `size=5` 返回 5 条。两次第一页前 5 个 ID 仅重合 3 个，采集须固定查询参数与排序并核对分页重叠。
- 筛选字典快照 `data/private/mca-filter-retry-20261118.json` 的 SHA-256 为 `4bb165aa8ea4d2066540dc01139ff7a1d79c468d0ac729d9662237c48e330f73`。根区划 35 项（大陆 31 省级地区、兵团、台湾、香港、澳门），广东级联 21 市；它们是选项，不是逐家机构覆盖证据。
- 私有字段审计脚本 `scripts/audit-mca-fields.py` 只输出字段路径、出现/非空次数和 JSON 类型，不输出字段值。当前试跑 19 页/190 行及 1 条详情共观察到 93 个字段路径（列表 35、基本详情 52、养老详情 6），其中 23 个在该小样本全为空；这些数字仅描述试跑，不能代表全站字段全集。对应报告为 Git 忽略的 `data/private/mca-institutions-2026-11-18/field-inventory.json`。

## 实体关联与冲突展示规则

1. 平台记录以 `(snapshotId, axbe0001)` 唯一；对现有目录先建立**候选关联**。同省/市 + 规范化名称 + 地址显著一致可进入人工确认队列；同名异址、同址不同名、一个企业多场所、一个场所多主体均不自动合并。若详情含有效统一社会信用代码，只确认登记主体候选，仍需地址/场所证据。

2. 已人工确认是同一场所后，机构名称、场所地址、平台列示床位、费用、服务功能等**同义展示字段**优先取该平台非空值，旁边显示平台来源与采集时刻；原广州/地市/QCC 值在来源对照中可见。用户指定的平台优先不等于覆盖原始快照或假定字段比旧来源更新。

3. 不同定义不构成可覆盖冲突：`registeredBeds` 与 `listedBeds`、工商注册地址与服务场所地址、企业登记状态与机构经营状态、平台评分与官方星级、费用区间与实际报价均独立展示。平台缺值不能拿其他源零填充；其他源值可单列并标来源，不假装平台确认。

4. 对同义值冲突产出 `{field, selectedValue, sourceRecordId, capturedAt, alternatives[]}` 的审计记录；不丢掉旧值。实体合并/拆分有版本和审核人记录，撤销只重建关联投影，不修改冻结原件。


## 筛选与交付门槛

- 当前字典已实测：经营方式 4、位置 3、医疗开展方式 3、收住人员类别 4、自理能力 3、总费用区间 8、三级网络层级 3、申请等级 5。长护险定点/医养结合是独立复选条件；其真实逐条布尔字段和时效需详情复核。
- `McaInstitutionIndex` 仅放确实采得且清洗通过的筛选字段；UI 使用真实字典值与 URL 参数，组合筛选后显示匹配数、空态、清除和来源日期。未知值单列，不把未知当否；缺字段的筛选控件不得假装可用。费用按平台实际单位显示，星级与平台评价分离。
- 数据流建议：官网限速采集 → Git 忽略私有原始响应/失败页/哈希清单 → 清洗与人工关联 → 新 `public/data/mca-institutions/` manifest + 省市 index/chunks → 校验的只读 loader/search → 独立官方平台目录/详情 → 已确认关联场所的字段对照。发布前核查再展示边界与个人字段。
- 当前 Next 使用 `output: export`，`/quanguo/cankao/detail/` 等详情路由是单个客户端查询页。不要为接口总数生成约 3.9 万个静态 HTML：复用省市 JSON 分块与单详情路由，避免构建、部署、缓存和浏览器首载成本失控。列表 `size=100` 被裁至 10；未传补贴过滤约需 3,939 页，若每条另查两个详情端点，约 7.9 万次详情请求，必须可续跑、限速、检查重复/缺页/总量漂移。
- 构建门禁：记录每次请求参数、时间、HTTP/业务码、页码、条数、唯一 `mcaId` 数、重复/缺页与校验哈希；不同时间总数漂移时标记不完整，不以当次 `total` 冒充已采全量。校验原值、null/0、费用区间、护理床位、字典码和联系方式遮蔽；静态包隔离扫描不得带原始联系人/自由文本。
- 测试/回滚：用脱敏样本覆盖映射、异常、同名异址、字段冲突和筛选组合；运行类型/全测试/静态构建、320–1440px 与键盘/错误恢复真实浏览器检查。新源版本单独发布；失败退回旧 manifest/版本，不覆盖已上线 QCC 和地市来源。
