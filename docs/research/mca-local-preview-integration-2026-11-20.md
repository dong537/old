# MCA 已观察快照接入方案（2026-11-20）

## 目标与范围

把已封存的全国养老服务信息平台列表与逐家详情原件清洗为可重建的私有 JSON，在现有项目提供本机只读预览。家属可以按已观察地区和关键词查找，查看机构摘要、已取得的详情和逐字段来源。首版成功标准：ID 不误并、原值不丢、缺详情不补造、筛选仅使用已解码值、浏览器可从列表进入详情并返回。当前不宣称全国全量、实时在营或可预约，也不修改现有广州、地方官方、企查查目录。

## 数据权威与流向

不可变 HTTP 响应与采集收据是原件；清洗器只读封存件，写入 `data/private/generated/mca-observed-catalog/current.json` 和按快照 ID 固定的 `snapshots/<snapshotId>/`。列表索引仅供检索，详情文件保留原始 `sourceFields`、采集时间、端点与哈希。`null`、缺键、数字零和冲突分别保留。快照状态固定为 `nationalComplete=false`、`publishable=false`。再次采集后运行清洗器生成新快照，原快照不被原地改写。

Next.js 开发态 `ELDERCARE_PRIVATE_PREVIEW=1` 经固定目录 loader 读取 manifest/index，详情先以平台 ID 在索引中定位，再校验哈希文件名并读取单文件。生产静态导出使用不读取私有目录的 stub；私有 JSON 不复制进 `public/`、`out/` 或生产 bundle。浏览器的筛选与页码在 URL，服务端只负责固定快照读取。

## 模块与接口

- 清洗脚本：原件/收据校验、ID 去重、字段与冲突保真、原子快照切换。
- `lib/mca-preview-*`：快照类型、私有 reader、公开 stub；拒绝不在索引内的 ID 和路径穿越。
- `/quanguo/mca-preview/`：本机预览列表。`/quanguo/mca-preview/[id]/`：同一快照下逐家详情。两者与现有公开目录分开。
- 列表组件：关键词、地区、可证实维度筛选、分页、摘要和覆盖说明；详情组件：基本信息、可用详情、原值与来源。

ID 只代表平台记录，不是统一社会信用代码。金额仅称平台列示元/月，不推断实际报价；床位仅称平台列示床位，不推断空床。缺详情记录可从列表进入详情，但需要明示“详情尚未采集”。

## 失败、回滚与验证

缺 `current.json` 或 JSON 损坏须显示明确错误，不能降成空结果；未知 ID 返回 404，详情文件缺失或 ID 冲突必须停止显示错误数据。清洗失败不切换 `current.json`，旧快照仍可供本机查看。页面回滚只需移除本机预览路由与 loader alias；原件、清洗快照保留。

验证包括清洗器离线测试、ID/字段/哈希抽样、TypeScript 检查、相关测试、公开静态构建的私有信息扫描，以及本机真实浏览器的列表→筛选→详情→来源→返回、窄屏和键盘路径。采集进程运行时不调用会触发站点互斥探针的采集 CLI。
