# 全国机构 CSV 接入与统一详情契约（2026-11-23）

## 目标与范围

面向家属，把用户提供的 2026-11-23 机构 CSV 全部 3,497 条接入现有全国平台目录，逐家拥有可访问详情；原有非重合索引继续保留。详情按同一组用户可读字段呈现，图片暂不展示或发布。成功标准是按 org_id 去重、首中末及采集状态 stale 的详情可达、床位/费用/服务口径正确、来源与采集状态可辨、静态构建及公开隔离扫描通过。不新增预约、机构在营/空床判断或全国全量声明。

## Source of Truth 与数据流

原始 CSV 由用户本机提供，导入时计算 SHA-256 并锁定 52 列表头、行数和唯一 org_id；原件仅留私有路径，不直接复制进 public。现有 public/data/mca-observed v1 保持不变，仍是历史观察记录真值。新 public/data/mca-catalog v1 是从 CSV 与旧公开索引生成的版本化公开投影，manifest 记录 CSV 哈希、导出日期、旧快照 ID、原件/交集/并集/详情计数。构建期 loader 校验投影并按 ID 读取；浏览器只下载紧凑统一索引。旧快照更新导致锁不匹配时构建失败，需重跑导入。

CSV 的 status=ok/stale 是采集器状态，绝不映为机构在营；updated_at 无时区，只显示为采集器记录时间原值，不伪造 UTC；risk_level 只保留原码，不推断风险评级。found_date 保留日期原值，在语义未核定前不冒充工商成立日期。total_beds、beds、nursing_beds 分别呈现总床位、来源全托床位、护理型床位。零收费不等于免费，缺失不等于零。images_json 仅含文件标识，按本轮要求不进入公开投影或 UI。

## 模块与接口

- 导入脚本：严格解析 CSV、类型化 51 个可公开列、生成版本化 manifest/统一 index/详情数据；输入路径和输出目录明确，重复 ID、非法数值/JSON、字段漂移直接失败。
- DTO 与 repository：lib/mca-catalog-* 定义来源字段、空值、collector 状态及索引卡片，服务端 loader 校验 manifest/index/详情并按 ID 查询；旧观察详情通过原 loader 保留。
- UI：现有全国平台列表读取统一索引；详情静态路由枚举并集中的可用详情 ID。CSV 详情与旧观察详情映射为同一展示结构；重复 ID 以 CSV 行为主展示来源，不按名称合并，也不偷偷把旧字段混入 CSV。
- 发布边界：check-public-output 只放行且验证新投影的固定文件路径/schema，继续拦截私有原件、图片标识、已知私有标识及未公开联系号码。生成 JSON 不包括原始 CSV、采集 token 或图片文件名。

## 状态、失败、迁移与验证

首次进入列表显示加载；索引或详情校验失败给可恢复错误，不能返回空成功。stale 仍可按用户“全部导入”的要求展示，但首屏说明资料待刷新并提供官网核对出口；官网快照不表示当前在营、空床或报价。回滚为撤销统一目录读取与路由接线、移除新投影，旧 mca-observed v1 不迁移。测试覆盖 CSV 52 列契约、3,497 行/唯一 ID/SHA、51 列投影、交集与优先级、字段口径、3 条 stale、首中末路由、列表筛选/返回、私有隔离、完整测试/类型检查/构建，以及 320/375/768/1024/1440px 浏览器自测。

本批次可在项目根目录运行 npx tsx scripts/import-mca-catalog.ts --input "<本机 CSV 路径>" 重建投影，再运行 npm run verify:release。导入器锁定了本批次 SHA-256、52 列顺序和计数；后续新批次先核对来源和字段，再更新来源锁及预期计数，不能只替换文件后沿用旧快照声明。公开产物位于 public/data/mca-catalog/，原 CSV 不放入 public。
