# 全国平台已观察快照接入（2026-11-21）

## 目标、边界与验收

面向查找养老机构的家属，新增独立的全国平台**部分采集快照**目录和详情，用已采集的字段填充页面；用户已确认逐家文字、收费、联系人、电话及图片的公开展示授权。本次不把该快照计作全国完整在营名录，不改既有全量发布门禁，不提供实时空床、预约、地图或图片文件 ID 到图片 URL 的推断。

验收：3,726 个已观察平台 ID 均可在目录查询；131 条双端点详情可进入详情页；3,595 条仅列表记录只呈现列表已观察字段并可到官网原页。0、缺失、冲突分别展示。来源、逐家采集时间与批次时间不混用；公开产物不含原始响应、签名、私有路径或未解释的系统字段。准确条数以重导出后的机器验收为准。

## Source of Truth 与数据流

采集原件和私有规范化快照位于 data/private/，只读。其观察值、字段冲突及采集时间是事实来源；公开 JSON 是白名单派生投影，不反写原件，也不覆盖地方名录和企查查目录。流向：官方响应 → 私有快照 → lib/mca-preview-dto.ts 映射 → scripts/build-mca-observed-export.ts → public/data/mca-observed/ → 静态路由与浏览器目录筛选。每次采集批次可更新投影；页面明确标为非实时，单家详情展示该家的采集时间范围，批次最晚时间只作批次元数据。

## 模块与接口

- 私有采集与规范化负责原件、观察次数、端点归属和冲突，不因公开页面改变原数据。
- DTO 映射负责字段语义、单位和 observed / missing / conflict；列表手机号、服务类别、补贴原码、日托床位、全托床位从已观察列表字段提取。详情字段只在实际详情端点或有证据的列表回填存在时给出值。
- 导出器只写已审阅字段，索引与详情按平台 ID 关联；时间类型为 null 或 {earliest:string,latest:string}，有对应观察次数时必须为非空且有序。详情链接使用散列文件名，源页用平台 ID 生成。
- 公开扫描器逐键检查结构、来源链接、计数及文件集合；任何未批准键或缺失文件构建失败。
- UI 读取公开投影；URL 保存关键词、地区与筛选状态。不存在的详情、网络失败或坏 JSON 呈现错误与返回路径，不伪造内容。

静态 JSON 不提供写权限、价格更新接口或机构认领接口；后续企业自主上传和编辑文章须另立授权、审核、审计与来源区分方案，不能直接改写此快照。图片现只观察到文件 ID/数量，缺少可核实展示 URL，因此页面不显示图片。

## 失败、回滚与验证

部分地区和详情仍未采全，展示页不得暗示覆盖完整或当前在营。跨端点冲突保留冲突状态，不按较新时间自动选值。导出器先在同盘私有目录构建完整临时投影并校验，再交换公开目录；写入或校验失败保留旧版，交换失败恢复旧目录。新批次不保留旧批次多余详情。进程崩溃留下的暂存/备份不进入 public；恢复发布前须检查私有备份与公开目录状态。私有快照不变。

验证依次运行 DTO/导出器及隔离测试、真实快照合同测试、typecheck、全量 release 构建、桌面与移动端浏览器任务检查。部署不在本次范围；不得把本地构建通过等同于生产上线。
