# 跨省候选主体目录任务布局依据

访问日期：2026-11-16。以下记录基于页面原始 HTML 和抽取正文；未取得浏览器视觉截图，不据此判断具体颜色、间距或移动端样式。

| 样本与角色 | 可核验页面 | 实际观察 | 本项目采用与差异 |
| --- | --- | --- | --- |
| 民政部“全国养老机构信息查询”，家属查机构 | https://app.gjzwfw.gov.cn/jmopen/webapp/html5/qgyljgxxcx/index.html | HTML 含机构名称、所属区划、验证码、查询/重置；结果列地区、机构名、统一社会信用代码、地址、床位数，含无结果与分页容器。 | 采用地区→检索→结果的任务顺序；企查查候选库不照搬“机构”身份、床位或联系方式。验证码也不表示可批量采集。 |
| 福建省民政厅“福建省养老机构”，家属查本地机构 | https://mzt.fujian.gov.cn/bmcx_ls/fjsyljg/ | HTML 含机构名/地址搜索、名称/通讯地址列表、分页与无数据提示。 | 采用可恢复的空结果与分页；本项目必须按省市拆分数据，详情显示导出快照及行号。 |
| 本项目广东登记主体候选库，研究登记事实 | 本仓库 app/guangdong/zhuti/、components/QccDirectoryView.tsx 与 QccDetailView.tsx | 已有名称/城市/类型/状态筛选、分页、来源详情及登记与机构身份区分。 | 复用页面壳、文案语义和状态处理；全国 141,364 行改为城市按需加载，避免复制广东全量索引首包。 |

首访路径：选省市 → 输入名称或选类型/状态 → 查看候选列表 → 打开登记详情与来源 → 返回同一筛选。回访路径：直接打开带地区和筛选参数的 URL。无城市、错误参数、无结果、网络失败与数据快照不一致都给出明确恢复操作。该调研是自查布局证据，不替代用户测试；企查查官网和国家企业信用信息公示系统页面本轮未可靠访问，不引用其布局。
