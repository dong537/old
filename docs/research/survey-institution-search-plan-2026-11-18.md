# 调研网站逐家养老机构检索执行记录

日期：2026-11-18。目标：在用户提供的 15 个网站内寻找可定位的养老机构信息，与本站现有名称、地址、行号和工商候选保持可追溯关联；全国检索目标继续推进，本批不是全站或全国全量完成。

## 范围、数据流和边界

- 原件和当前公开快照是本批核对输入，网站原文用于确认可见内容及访问状态；外部网页 → 本机私有证据 → 候选匹配/字段冲突清单 → 研究报告。不改公开目录、路由、UI、权限或部署。
- O05/O06 对已归档的重庆、深圳逐家官方表做全行核对；C01–C03 查可正常访问的具体机构页；O01–O04 尝试正常查询，记录真实成功/失败而不是把表头当结果；S01–S06 查是否有对应机构原文，区分政策提及与机构档案。
- 私有核对文件 owner 为研究流程，机构字段仍各自归属于原站；不引入全局优先值，不把新页面访问日作为逐家资料期。有效期随源资料期保留，未知用 null。
- 匹配接口：同城名称键；仅统一空白及括号形式。输出保留一对多候选，不自动选首条；费用、服务、床位、状态的分歧不覆盖。公开来源或注册登记仍不证明当前在营、空床或实际运营关系。
- 联系人个人信息不进入本批清单；商业网站的小样本证据只留研究，不进入生产公开数据。登录、验证码、robots/访问限制不绕过，未完成查询不能记作未收录。

## 验证与回滚

- 先核输入 SHA-256/快照与行数，核对每个官方来源行恰好有一条输出、来源序号和 ID 唯一、候选全部来自目标同城索引；断言输出不含电话/负责人字段。
- 用第二次独立读取检查 JSON/CSV 的行数、匹配与未匹配分区、重复名称、床位未知及冲突计数；抽核首/中/末来源定位。
- 本次仅私有数据和研究文档，不运行无关前端构建，不把上次浏览器验收冒充本次数据验收。回滚仅删除本批新建私有审计产物，不触及用户原件或当前公开快照。

## 当前状态

2026-11-18 用户调整优先级：暂缓床位差异逐条复核，先用并行调查尽快取得可再展示的批量名录、补全现有全国目录并完成本地上线门禁。重庆/深圳差异作为研究记录保留，不新增面向床位差异的生产代码或单独批量流程。三个检索组分别核公开平台、北京上海及缺口地区；主任务处理导入门槛和发布验证。最终证据与未完成范围写入总报告。
