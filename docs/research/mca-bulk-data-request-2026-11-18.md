# 全国养老服务信息平台机构数据申请与咨询稿（未发送）

## 申请目的

拟在养老信源网站为家属提供可核对来源的养老机构检索、筛选和档案，保留平台机构 ID、原始来源链接、资料日期及旧版本对照；不把平台展示值称作实时在营、空床或现价。希望通过平台认可的批量下载或正式 API 获得机构列表与逐家公开详情，以避免网页分页不稳定和自动请求限流。

## 政府信息公开申请：现有文件

根据民政部[《政府信息公开指南》](https://www.mca.gov.cn/gdnps/pc/content.jsp?id=114710&mtype=2)，可从[在线申请入口](https://www.mca.gov.cn/n2445/ysqgk_index.html)提交现有政府信息的申请。拟申请内容为：截至申请时机关**已经制作或获取**、可提供电子副本的全国养老机构逐家名录或现有导出文件，以及随文件已有的字段说明、统计口径、数据截至日期和更新周期。优先接收 CSV/XLSX/JSON 原件，保留原机构 ID、行政区划代码、机构类型与原字段；若机关没有该现成文件，请告知现有可申请的文件名称、保管机关或公开渠道。

申请不要求机关为本项目新编程序、定制 API、另行分析或加工数据。公开申请与第三方网站再展示授权是两个独立问题；取得文件不自动等于获准批量转载。按指南，普通申请原则上不收费，数量或频次明显超过合理范围时可能收取信息处理费；这不是接口积分或 API 额度。2026-11-19 已核对在线申请表单可打开，尚未填写或提交。

可复制到“所需信息”栏：**申请获取贵部已经制作或获取的全国养老服务信息平台养老机构逐家名录现有电子文件，以及该文件随附的字段说明、数据范围、统计口径、资料截至日期和更新周期。希望按现有格式提供，不要求贵部另行加工、分析或开发接口。如无该现有文件，请告知可申请的文件名称、保管机关或已公开的获取渠道。**申请人的姓名、证件与联系方式须由申请人本人在官方表单填写，不放入本项目仓库。

## 平台留言咨询：接口与使用许可

通过[民政部留言咨询入口](https://www.mca.gov.cn/consult/index.jsp)单独询问：

1. 是否提供正式批量下载或稳定分页 API；若提供，请说明入口、鉴权、允许的请求频率/并发、更新周期、历史版本、稳定游标或唯一 ID 排序及完整性校验方法。
2. 数据范围与口径：仅“养老机构”还是包含社区设施等；无补贴过滤与“仅显示补贴参与机构”的差异；31 个省级地区的收录边界、停业/撤销/未更新记录的标记，以及总量的统计时点。
3. 字段字典与单位：机构性质、服务、医疗开展方式、收住能力、收费区间、总床位/护理床位、星级与评价；零、空值、未知和未填报的区别。
4. 书面明确逐家非个人字段在本网站展示、缓存、检索及与地方官方来源和登记主体候选关联的许可边界；署名、原页链接、资料日期、更新/删除责任，以及机构服务电话、图片和简介的再展示要求。
5. 如无全国渠道，是否有省/市可验证导出或开放数据资源编号，以及如何处理直接挂省市级的机构记录。

可复制的咨询摘要：**我们建设面向家属的养老机构来源核对网站，拟合法获取全国养老服务信息平台逐家机构公开字段。请问是否有正式批量文件或 API？若有，如何申请、允许的请求额度、稳定分页/快照规则是什么？逐家非个人字段可否在注明来源及资料日期后由第三方网站缓存、检索和展示，具体书面许可条件是什么？**

## 隐私与使用边界说明

申请范围不包括住养老人、家属、身份证照片、户籍/居住地址、紧急联系人等个人资料。联系人姓名与个人手机号在未获必要依据前不公开。机构自行填报的费用、床位和服务条件在网站标注来源与资料时间，并提示用户向机构复核。若同一场所的其他来源数据有冲突，平台同义非空字段优先显示，但旧值与来源保留供审计。

## 当前技术证据

2026-11-18 官网公开列表在未勾选补贴条件时报告全国 `total=39,384`、广东 `1,422`；单次请求最多返回 10 行。广东默认口径目前保存 20/143 页、200 行，但只有 145 个不同平台 ID，出现 55 次跨页重复；早先有界试跑还遇到 11 次 HTTP 429。番禺区 `checkSort=1` 两轮各 3 页、22 个 ID 完全一致，但广东同排序的尾页样本仍出现跨页重复。现存省级样本有 2 条直接挂省级区划，不能只合并区县分片。因此不能通过继续翻页或简单分片证明全国完整。上述均为接口口径/技术试验，不是已采集机构总数。详见 `mca-pagination-stability-2026-11-18.md`、`mca-panyu-repeat-2026-11-19.md` 和 `mca-integration-schema-2026-11-18.md`。

离线对账可运行 `python scripts/fetch-mca-institutions.py compare --area-code 440113000000 --check-sort --compare-folder data/private/mca-institutions-2026-11-18/area-440113000000-check-sort-1-repeat-20261119`。该命令仅比较本地缓存，不请求网站；`matchingCachedPageIds=true` 只表示两个缓存的分页 ID 一致，不证明缓存由独立请求产生，`snapshotVerified` 始终为 `false`。
