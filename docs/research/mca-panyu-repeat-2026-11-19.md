# 番禺区机构列表独立复测（2026-11-19）

## 范围与方法

仅验证全国养老服务信息平台机构列表的 `areaCode=440113000000`、`checkSort=1`。两轮分别保存在 Git 忽略的 `data/private/mca-institutions-2026-11-18/area-440113000000-check-sort-1/` 和 `area-440113000000-check-sort-1-repeat-20261119/`，没有覆盖原始响应。第二轮单进程、单线程，POST 请求间隔设为 10–15 秒，最多 3 页、每页 10 条、每页最多一次尝试；遇到 429 会停止并记录站点级冷却时间。

两轮对应页的 ID 集交集为 10 / 10、10 / 10、2 / 2，页内顺序也完全相同；两轮整体 ID 集均为同一组 22 个。第二轮没有记录 429。该结果证明**这两轮番禺区样本分页自洽且可复现**，不证明全国接口存在稳定唯一排序、不可变快照或已取齐所有机构。广东省 `checkSort=1` 的其他尾页样本曾出现跨页重复，因此不能将番禺的观察外推至全省。

## 代码状态与下一步

采集器现将 `pageAuditReconciled` 与 `complete` 分开：前者记录缓存页的页数、长度、总量和 ID 去重是否自洽；后者保持 `false`，因为 offset 分页没有获证的稳定快照或唯一排序。离线规范化器的公开导出仍被关闭。

下一步应先取得平台确认的批量文件、稳定游标/唯一排序和允许的请求额度，再按分区做同口径总量、ID、详情及字段审计。仅凭增加延迟或重复抓取，不能对 39,384 条接口报告值宣称完整采集。
