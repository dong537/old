## 本轮修正与剩余阻断

`scripts/normalize-mca-private.py` 原把 `orgBaseDetail.axbe0004` **拟映射**为 `facilityTypeCode`，虽未实际投影，但会误导后续字段开发。本轮仅修正私有字段账为候选标签并补一项离线行为测试；列表 `axbe0004` 的代码映射保持原值。星级码根据页面标题增加为未投影候选，未把它与用户评价或官方认定日期合并。

未解的重点包括：详情页独立前端脚本/标签尚未保存；`ahae2343`、`ahae0019`、嵌套收费/服务数组与部分风控字段尚无可靠释义；月费用的零值、星级 `00`、记录级更新时间及个人信息/再展示边界未核。旧响应 wrapper 不含原始 HTTP 字节，不能事后声称复核了原文哈希。即使将来把全部页号访问一遍，跨页漂移和父级直挂仍须独立对账，才能讨论全国完整与生产发布。`readyForFullProjection`、`snapshotVerified`、`publishable` 继续保持 `false`。

复核入口：`python -m unittest tests.test_mca_private_normalization -q`；字段路径统计可在本地执行 `scripts/audit-mca-fields.py`。本轮另执行 `python -m unittest discover -s tests -p test_mca_*.py -q`，**216 项通过**，以及 `python -m compileall -q scripts/normalize-mca-private.py` 和 `git diff --check`。本报告仅使用聚合计数和页面公开标签，不复制私有字段值。
