# 全国养老服务信息平台逐家接入：生产门槛（2026-11-19）

本审计只读核对本地 Next.js 工作树和私有缓存汇总；未访问官网、运行构建或修改代码，不能据此断言线上部署状态。目标是将平台机构作为独立、可追溯来源快照接入逐家列表和详情，不把接口总数、企查查登记主体数或地方历史来源行数冒充当前在营机构数。

## 现有数据链路

- [采集器](../../scripts/fetch-mca-institutions.py#L259-L306)保存请求/响应和哈希；[省级分片批次](../../scripts/collect-mca-shards.py#L52-L109)有站点锁、限速、429 中断与私有批次摘要，仍固定为 publishable=false、snapshotVerified=false。其无补贴筛选口径见[列表 manifest 构造](../../scripts/fetch-mca-institutions.py#L509-L524)。
- [规范化脚本](../../scripts/normalize-mca-private.py#L111-L166)只提取部分列表与详情字段；[质量报告及私有预览](../../scripts/normalize-mca-private.py#L254-L320)固定 readyForFullProjection=false、publishable=false，没有公开导出步骤。
- 公开站点当前分别展示[地方官方历史来源](../../app/quanguo/laiyuan/page.tsx#L11-L23)、[企查查机构线索](../../app/quanguo/cankao/page.tsx#L8-L19)和[企查查登记主体候选](../../app/quanguo/zhuti/page.tsx#L6-L15)；[静态导出配置](../../next.config.mjs#L10-L23)与[构建脚本](../../package.json#L16-L23)均未接入 MCA manifest、索引、详情分块或独立页面。public/data/ 当前无 mca-institutions/。
- [采集记录](./mca-direct-collection-2026-11-19.md#L20-L34)显示广东默认排序仅 20/143 页且 200 行中重复 ID 55 次；北京省级仅 22/63 页、220 个不同 ID、无详情，遇 429 停止。东城与杞县两轮小样本一致，仍不证明全国快照稳定。
