# 全国平台本机预览 DTO 与前端整理（2026-11-21）

## 目标与边界

目标：把已封存的 MCA JSON 索引转成明确的列表与详情展示契约，使相同字段在卡片和档案中采用相同口径；家属可区分观察值、未提供、来源冲突以及零值。沿用当前地区／关键词／设施类型筛选、分页、详情、来源和返回路径。此轮不改采集器、原始 JSON、官网接口、既有广州／全国公开目录，也不解除 `publishable=false` 的私有预览门禁。

## Source of Truth 与模块

采集原件及收据是源，`scripts/build-mca-observed-catalog.py` 从镜像生成不可变私有 JSON；`lib/mca-preview-local.ts` 校验并读取索引／逐家详情。新增 `lib/mca-preview-dto.ts` 只负责已映射索引字段 → 列表卡片 DTO、索引字段＋字段来源 → 详情 DTO，不重新解析未释义原键，也不写回 JSON。页面服务端先映射 DTO，再传给客户端组件；筛选只对 DTO 中保留的原值字段运算，不能对“未提供”文案运算。原始 `sourceFields` 仅在本机详情证据区展示。

## 展示契约

- 列表 DTO 保留平台 ID、名称／地址／地区层级／设施类型的可用原值供筛选；冲突字段即使残存旧值也不参与筛选，原值仍留在私有证据区。另给安全展示文案、床位、护理型床位、月费用范围、星级原码、平台评价、详情覆盖及观察次数。名称相同不合并平台 ID。
- 详情 DTO 的 16 个已映射字段按固定顺序生成 `{key,label,text,state,source}`；`state` 为 `observed | missing | conflict`。显式 `0` 是观察值，不等于空值；费用 0 不写成免费，零次评价不写成零分差评，标签原文不写成认证。字段冲突不选边，并指向原始证据。
- `source` 只提取端点标签与可读采集时间；SHA、源路径和全部原值仍在折叠的私有证据区。未知字段继续只在原始 JSON 中，不加猜测性标题或筛选。
- 路由、ID、单位（床位个、费用元／月）、UTC 原时间、URL 查询键、未找到与读取失败语义沿用现有实现。DTO 不包含实时营业、空床、预约、机构身份核验等推断。
- 详情页按基本信息、床位与费用、平台标签与评价分组；首屏先给设施类型、平台列示床位及月费用。平台 ID 与快照标识放在可展开的技术信息区，官网原页和返回原筛选保留为可见链接。

## 数据流、失败与验证

镜像／原件 → 私有清洗 JSON → 严格 loader → 纯 DTO 映射 → 本机列表／详情组件；生产构建继续使用公开空实现。映射不得掩盖 loader 的结构错误；仅字段值为 null 时显示缺失，冲突字段显示待核，来源无可读时间时显示未提供。旧页面回退可移除 DTO 映射并恢复原组件 props，私有 JSON 无迁移。

先以测试覆盖零值、单边费用、冲突、评价、原标签、来源以及 DTO 与原始 JSON 的分离，再改组件；运行 Python 清洗测试、全量前端测试、类型检查、生产构建及公开隔离扫描。本机浏览器复测搜索、筛选、列表→详情→来源→返回、窄屏和控制台。视觉维持既有 token 与官网“左筛选／结果卡”任务结构，优先改善信息层级，不能声称与当前官网像素级一致。

## 本机验收（2026-11-21）

- 前端全量测试 291/291、目录与原型 TypeScript 类型检查通过；私有目录清洗器相关离线 Python 测试 16/16。详情摘要的前端断言先失败再由实现转绿。
- 生产静态构建导出 3,401 页，公开隔离扫描检查 10,741 个文件通过；正式构建的预览详情仅保留 unavailable 占位路由。一次导出在 Windows 上遇到临时 EBUSY 文件锁；确认目标文件可独占打开后重跑成功，没有改动源数据或采集器。
- Playwright CLI 本机自测：广东省／广州市筛选匹配 145 个平台 ID；列表进入档案后可见分组事实和逐字段来源，来源链接定位原始证据，展开后能读取时间、SHA 与原键；返回保留省市筛选。320／375／768／1024／1440px 视口均无水平溢出，375px 截图检查了列表和详情首屏；控制台未见错误或警告。原生浏览器 200% 缩放及真实家属测试未做。
- 当前快照是 3,726 个平台 ID、131 个双端点详情；其余只有列表观察，不能视为全国完整机构资料。DTO 映射 16 个已识别字段，其余原键留在本机私有证据，不进入公开目录。
