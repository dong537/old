# 来源导向前台改版验收（2026-11-19）

本记录对应用户批准的两站布局对照与公开前台改版；设计范围见 `docs/superpowers/specs/2026-11-18-source-led-frontend-redesign.md`。以下均为本机开发者／代理自测，不代表家属用户测试；未部署到公网。

## 实施结果

- 首页改为地区＋关键词主入口，广州官方名单、全国机构线索和官方来源保持不同口径；页头统一为单层导航和手机菜单。
- 广州目录仅展示名称／地址、真实区县及预收费标记筛选；手机的按区筛选默认收起，选区后自动展开。机构卡把已有事实、来源和资料日期放在相邻位置。
- 广州入口、机构档案、全国线索和官方来源目录、服务记录、长护险指南按同一来源导向层级调整；移除空统计、未开放操作及无数据依据的筛选。保留静态路由、查询参数、隐私遮蔽、未知／零语义和返回原筛选。
- 改前／改后 320px 截图及最终部署前缀截图保存在 Git 忽略目录 `output/playwright/source-led-redesign-20261119/`。广州列表新增手机端折叠筛选后，首条结果卡顶部约 615px；该读数基于 320px 本机视口。

## 本机验证

- `npm run typecheck` 通过；`npm test` **267/267** 通过；在 `NEXT_PUBLIC_ELDERCARE_BASE_PATH=/eldercare` 下 `npm run build` 通过，导出 **3,399** 条静态路由，公开隔离扫描 **10,733** 个文件通过；`git diff --check` 通过。首次带前缀构建与本机 Next 开发进程共用 `.next` 时出现页面入口错误；停止该项目的开发进程后重建成功。
- 根路径静态预览的全国线索路径：广东→广州→关键词→详情→返回，省市、关键词与 1 条结果恢复；全国官方来源路径：重庆→关键词→详情→返回，来源日期、原表字段、官方原文链接和 1 条结果恢复。两条路径的 Playwright 控制台均 0 错误／0 警告。外站原文仅核对链接目标，未逐一验证第三方站点可用性。
- 广州机构档案、服务目录、长护险指南在 320/375px 均加载且无整页横向溢出或 page error；服务搜索的空结果和恢复、指南 FAQ 的 Enter 开合、档案横向导航焦点滚动均可用。另在 320px 验证广州目录按区筛选的 Enter 开合、12 个区／全部入口与选区后的 URL 保留；首条结果顶部约 615px。服务关键词搜索会保留在 URL 的 `q` 参数中。
- 带 `/eldercare` 前缀的最终静态预览在 320/1440px 各核对首页、广州入口／目录／档案、服务目录、长护险指南、全国线索及全国官方来源，共 **16** 个页面／视口组合：全部 HTTP 200、有 H1、无整页横向溢出、无 page error 或 HTTP 失败；CSS 和 JS 均从 `/eldercare/_next/` 加载。
