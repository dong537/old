# 民政部平台筛选字段与本站覆盖对照（2026-11-18）

## 证据与边界

筛选字典来自私有快照 `data/private/mca-filter-retry-20261118.json`，其时间为 2026-11-18。字典是网站可选项，不代表任一机构具有该属性；当前广东试跑仅 19 页、190 行、139 个不同平台 ID，且有跨页重复与 HTTP 429，不能据此发布全量目录。`lib/mca-filters.ts` 只对未来**已验收快照**中实际存在的规范化字段筛选；本轮没有把试跑数据写进 `public/`，也没有开放新的筛选 UI。

## 筛选契约

`McaFilterRecord` 使用平台 ID 保留同名异址场所，`facets` 的**属性缺席**表示未采集，`null` 表示已采集但未提供；数字/字符串代码如 `0` 不自动归为未知。`McaFacetCatalog` 只给审核过的代码及文案。`filterMcaRecords` 将字典选项与当前实际记录取交集；零条已知值的维度不显示，未知只在存在明确 `null` 且维度有已知值时可选。关键词、省市、各维度和页码可以组合，重复/无效参数会返回可见 `issues`，不把无效筛选伪装为零结果。计数基于传入的记录范围，调用方必须先验收该范围完整性。

接入 UI 前仍需：可复现的完整列表与详情快照、地区级联核验、每个筛选字段的逐条代码覆盖率、官方数据再展示边界、页面来源日期及缺值说明。当前广州目录中的“老人情况、月费、等级、长护险、医疗”仍保持不可用提示；不使用其他来源的不同口径数值填充民政部筛选。
