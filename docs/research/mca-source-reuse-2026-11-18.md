# 民政部全国养老服务信息平台来源与再展示核查（2026-11-18）

## 核查对象与证据


- [机构列表入口](https://yanglao.mca.gov.cn/?#/index/institutionList) 为浏览器应用。其机构列表页面脚本 [`chunk-3d5896b7.22ca4f71.js`](https://yanglao.mca.gov.cn/js/chunk-3d5896b7.22ca4f71.js) 的可见提示为：“以下信息由养老机构提供，详情请与机构联系”。这说明网页承载机构提供的资料；官网域名本身不能证明每个机构的状态、床位、收费和电话已由民政部门逐项核准或仍为当前值。
- 主脚本 [`app.b1ecf853.js`](https://yanglao.mca.gov.cn/js/app.b1ecf853.js) 的页脚文字为“版权所有：中华人民共和国民政部”。这是版权归属声明，不是本站批量抓取、复制全部逐家字段或再公开展示的明确许可。
- 机构详情使用的共享脚本 [`chunk-3f07518e.f8bff454.js`](https://yanglao.mca.gov.cn/js/chunk-3f07518e.f8bff454.js) 可见联系电话、联系人等标签，也出现身份证照片、户籍地址、居住地址和紧急联系人等个人资料标签。脚本被共享并不证明这些个人资料出现在公开机构详情，但说明不能将详情接口返回的所有键无差别采集、投影或发布。
- `https://yanglao.mca.gov.cn/robots.txt` 在本轮访问返回 `200 text/html` 的应用 HTML 外壳，而非可解析的 robots 指令；不能把该响应解释为允许或禁止批量采集。机构列表、详情脚本及页脚中，本轮未找到明确的逐行再展示许可或下载授权。未找到不等于不存在，应以平台运营方的正式授权或开放数据许可为准。

## 字段与优先级边界


| 数据 | 本轮判断 | 接入建议 |
| --- | --- | --- |
| 机构名称、地址、行政区、设施类别、床位、费用、评级 | 页面拟公开展示，但各行可能由机构填报且缺失资料日期 | 可先作私有核对快照，逐项保留原始值、来源 URL、抓取时间与空值；公开批量复制前核实再展示权限 |
| 机构公开服务电话、联系人 | 不保证为非个人联系方式，也可能过期 | 仅在确认机构对外公开用途与许可后展示；联系人姓名、手机号先不进公开投影 |
| 介绍、图片、自由文本、嵌套对象 | 可能含图片版权、个人资料或未经审定内容 | 私有采集也先做白名单和敏感信息扫描；不因“所有字段”要求直接公开 |
| 身份证、家庭/户籍地址、紧急联系人等居民资料 | 共享脚本中出现，但非机构目录的必要数据 | 不采集、不保存、不展示；若 API 意外返回，必须拒绝写入公开数据 |

用户指定的“官方平台优先”可作为**显示优先级规则**，但仅在统一社会信用代码、明确官方机构 ID 或严格核对的同一场所匹配后按同字段处理。旧来源值、来源日期和冲突原因须保留；不得用一次页面抓取时间冒充资料更新日期。官网提示机构提供资料，故“平台来源优先展示”不能改写成“机构现况绝对可信”。

## 当前发布决定


已授权的本地数据研究可以继续获取公开机构列表/详情的最小必要字段并做私有清洗与对账，按适度限速与失败续跑执行。**在批量再展示范围与敏感字段审核未落实前，不将这批逐家原始数据或全量详情写入 `public/` 或线上页面。**筛选字典、接口 schema 与地区层级可先用于字段设计和测试，但具体筛选项必须由已接入的数据字段支撑，不能空壳上线。

## 证据限制


官网访问存在网络路径差异：2026-11-18 部分浏览器请求为 403/502，签名 API 与筛选字典经另一请求路径可返回 200。上述结论只覆盖本轮打开的入口、主脚本和列表/详情相关脚本；没有取得独立的转载授权文件或运营方书面答复，也未逐字段核实未带补贴筛选时接口报告的 39,384 条记录。
