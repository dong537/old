# 四个导航入口按 dist 原型开放（2026-11-23）

## 目标、范围与成功标准

面向替家人查找养老服务的用户，开放找上门服务、长护险指南、价格参考、榜单四个全国导航入口。沿用 dist(1) 的信息顺序：标题与口径、来源提示、筛选或分类、结果卡片、方法与来源；沿用本站现有色彩、导航和可访问控件。打开链接须有真实内容、可用操作和返回入口。不要复制原型 lib/seed.ts 的虚构机构、报价、评级、回访和预约，也不把广州规则泛化为全国规则。

保留现有全国机构目录、详情路由、来源边界及静态导出。替换四个“待开放”为内部链接，开放首页对应服务入口。此次不做预约、在线认领、真实空床、个人护工目录、主观质量排名，也不加入地图或图片。四页均为来源快照而非实时交易服务。

## Source of Truth、模块与数据流

- 上门服务：public/data/mca-catalog 的锁定 CSV 投影中，服务类别明示上门/居家或上门项目非空的机构作为线索；字段来自 McaCatalogCsvFields，按 org_id 精确链接现有平台详情。广州医保历史考核与公示的 251 条仍由 public/data/guangzhou-services.v1.json 管理，作为不同来源单独入口，不等同当前上门能力。
- 长护险：现有 lib/ltci-guide.ts 与 app/guangzhou/changhuxian/page.tsx 的政策来源仅适用于广州；全国入口先解释地区差异，提供广州详细指南和有日期的医保来源出口。补贴页不是长护险。
- 价格：仅从锁定 CSV 目录索引中非空、完整且单位一致的月总费用上下限计算样本数，逐家展示；床位费、护理费和膳食费分项在现有详情中查看。明确来源为平台列示区间，不做原型按护理需求 A–D 分档，不把 0 元解释成免费。方法与样本量在页面可见。
- 榜单：沿用原型的机构／上门服务分类、收费透明／回访兑现／报错响应三卡与方法展开。现有 CSV 不含可核验的报价审计、履约回访及报错处理闭环，因此六项均按证据不足显示“不发布”。床位数与评价次数不等于质量、推荐或当前规模，不造评级、考核等次或回访。

构建期从已校验公开投影读取、聚合并生成静态页面；页面不直连政府接口。筛选、分页和分类状态存在 URL 或局部 client state，失败与空结果明确说明如何返回。外部来源链接指向原文，所有内部详情使用现有站内路由及 base path。源数据不因汇总页面而改写；每项统计说明单位、范围、时间和样本口径。

## 页面路径与控件契约

- /quanguo/shangmen/：关键词、省市、服务项目筛选，卡片展示名称、地区、明确列示的上门信息与来源，链接现有机构详情；缺项显示未提供。首屏说明当前仅覆盖已有 CSV 的京津冀晋及内蒙古，另给广州医保历史记录入口。
- /quanguo/changhuxian/：常见问题可展开，机构护理/居家护理分栏指向已有来源，明确详细办理资料目前仅广州可核对。其他地区提示到当地医保主管部门，不输出统一资格或待遇数字。
- /quanguo/jiage/：以原型的摘要卡和明细表结构组织目录索引中已有的月总费用，以省市筛选替代无真实依据的护理档位；附样本数、地区范围、计算方法及机构详情出口，分项在详情中查看。
- /quanguo/bangdan/：养老机构/上门服务分类与单项卡片，逐卡说明指标、证据缺口和“怎么算的”；现有质量榜均因缺少可核验证据而不发布。

## 失败模式、验证与回滚

阻止未知值、零值、旧快照与当前状态混淆；不将平台标签视为资质。不从原型导入 seed。数据或投影文件缺失时构建失败，页面不得以空数组假装成功。筛选无结果时保留清除入口；详情返回保留筛选上下文。测试真实来源字段与聚合公式、零值/缺失/无结果、路径和筛选，随后运行类型检查、全量测试、静态构建及公开输出扫描。浏览器在 320/375/768/1024/1440px 检查导航、主流程、键盘、溢出和控制台。回滚只需撤销四个新路由与导航连接，不变更既有机构及医保来源数据。

## 页面自测清单

家属首次进入应先看覆盖和资料日期，再筛选/读费用/看方法，最后打开来源详情；回访可经同一路由和 URL 找回条件。每页检查初始、无结果、字段缺失、长机构名及来源不足状态。dist(1) 是视觉与任务路径参照，示例业务数据和预约动作不进入本站。

## 实施结果与原型差异

- 四个主导航均接入 `/quanguo/` 路由，首页上门服务卡同步开放；新页不再附加会跳到无关目录的共享搜索框。筛选与详情之间的 `from` 只接收三条已知全国目录路径及各自白名单参数，拒绝外部地址、重复参数、未知参数和无效页码。
- 上门目录按平台 ID 投影 1,746 条明示服务类别／项目的机构，支持省、市／区县、项目、关键词与每页 12 条分页。资料只覆盖已有 CSV 的五个省级地区；不是全国全量服务商或当前接单证明。
- 价格页使用真实月费索引的 2,328 条完整区间，每页 20 条；1,169 条缺少可用完整区间不纳入。28 条 0–0 原值不解释为免费，3 条待刷新逐条提示。原型的护理需求分档与虚构行情卡改为可追溯的省级样本入口；分项费用继续在机构详情查看。
- 长护险保留原型问答、机构护理／居家护理双栏及来源顺序。仅广州已有逐项办理来源，全国入口明确这一边界，不推广广州待遇或申请条件。
- 榜单保留原型两类切换、三项指标卡与原生方法展开；本期没有真实质量名次。原型依赖的认领、报价核验、回访和报错闭环数据尚不存在，不输出评级或分数。
- Server → Client 的查询状态使用字符串，避免 URLSearchParams 跨组件边界导致静态导出失败。服务详情统一定位始终存在的“服务信息”，修正 69 条仅标服务类别、没有其他服务组的记录的失效锚点；有真实机构数据的回归测试覆盖该失败路径。
