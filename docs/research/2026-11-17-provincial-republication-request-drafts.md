# 辽宁与云南省级养老机构资料再展示许可申请草稿（2026-11-17，未发送）

用途：把已正常取得、已逐行核对的两份省级资料从私有查漏提升为可公开使用的来源。本文仅供项目方审阅；没有发送、提交、取得许可或更新网站公开目录。正式联系前，项目方须补充真实申请主体、经办人、联系方式、站点域名及收费/商业模式；本草稿或口头答复不等于书面授权。

## 辽宁省民政厅

对应原件：[《2024年全省养老服务供给信息表》发布页](https://mzt.ln.gov.cn/mzt/zfxxgk/fdzdgknr/ylfw/jgxx/440F2BC00FF248B8800BF67C529E3C61/index.shtml)，网页发布于 2025-12-02。本站私有取得附件 liaoning-supply-2024.xlsx，SHA-256 71cfd254833ae2a24e79b21e22386d3703dd42467fef765c996c887e4174e5d4，含辽宁 14 市 2,375 条名称记录；原件另有联系人和电话，本站拟排除。原页的转载限制尚未授予本站逐项展示权。

建议申请正文：

> 我方拟建设面向老年人家属的养老机构信源平台，已从贵厅上述公开页面取得《2024年全省养老服务供给信息表》。拟仅将附件中的市级、机构名称、所在区、机构地址及明确的资料年份，经核对后以可搜索、分页的历史来源记录形式向公众展示；不展示联系人姓名、联系电话，不以该表宣称机构当前仍在营、仍有空床或全省完整覆盖。每条记录将注明贵厅原文链接、附件名称、资料年份、本站获取与更新日期，并保留纠错、撤回机制。烦请书面确认：是否允许我方在可能含商业服务的公开网站复制、结构化加工、缓存、逐条展示及与其他来源作“待核候选关联”；允许的具体字段、署名方式、许可期限、更新频率、撤回和纠错要求是什么？如已有更新版本或正式开放接口，也请告知取得途径。未获明确允许前，我方不会公开投影该表的逐家数据。

## 云南省民政厅

对应原件：[《正常运营状态养老机构信息》官方页](https://ynmz.yn.gov.cn/zwgk/fdzdgknr/ylfw/202506/t20250616_3819534.html)，网页发布于 2025-06-16；本站私有核得 834 条，覆盖 16 州市。页面未说明逐家数据截至日，表含负责人姓名。另见[官网网站声明](https://ynmz.yn.gov.cn/ggbf/mzsm/202511/t20251111_2756594.html)，要求明确书面同意，不能直接依公开可读推断可转载。

建议申请正文：

> 我方拟建设面向老年人家属的养老机构信源平台，希望将贵厅《正常运营状态养老机构信息》中的州市、区县、机构名称及地址作为带来源与日期的历史名单供公众核对；负责人姓名不进入平台，也不把 2025 年页面标题中的状态表述为今天仍正常运营。烦请书面确认：我方能否在可能含商业服务的公开网站复制、清洗、缓存、逐条展示上述非个人字段，允许的署名、许可期限、数据更新、用户纠错、数据撤回及与其他来源作“待核候选关联”的边界是什么？若有更新的机构名单、逐家资料截至日或正式开放数据渠道，也请告知。取得明确授权前，我方只在私有环境用于缺漏核对，不公开逐条记录。

## 收到回复后的处理

1. 保存原始回复及申请主体材料到 Git 忽略的私有权利证据目录，记录提供方、版本、适用网站与字段、期限、署名、反馈、撤回要求和文件哈希；公开仓库只存不含个人资料的许可状态摘要。
2. 逐项把授权字段与原件列对照，排除联系人、电话及负责人姓名；资料截至日未知时维持未知，不能用页面发布日期代替。
3. 先做私有投影、字段白名单和来源哈希行为测试，再接入公开快照、重算企查查同名候选，重新完成隔离扫描、构建和真实浏览器验收。拒绝或仅许可私用时，继续私有查漏，公开来源行保持不变。
