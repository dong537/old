# 民政部全国养老服务信息平台机构列表核查（2026-11-18）

## 入口与实测

用户指定入口：`https://yanglao.mca.gov.cn/?#/index/institutionList`。静态页面及脚本可访问；前端使用的真实列表接口为 `POST https://yanglao.mca.gov.cn/ylxxptapi/ylfwpt/ylfw/queryOrganizationDataList`。本轮匿名请求第一页（`current=1`、`size=5`、`ahae0635=1`）返回 HTTP 502；按页面脚本要求附带公开计算的 `X-Auth-*` 请求头重试仍为 502。真实 Chromium 打开同一页面时，列表请求与地区、筛选字典请求也返回 502，页面仅显示筛选外壳而无机构卡片。因此没有取得实时总数或任何逐家记录，不能把历史估计数写为本轮实测。浏览器控制台证据在 Git 忽略的 `.playwright-cli/console-2026-11-18T11-02-13-317Z.log`。

## 页面可见的数据契约

页面脚本定义地区、机构性质、医疗条件、收住能力、月费区间、星级等筛选。列表卡片预期显示名称、详细地址、费用上下限、总床位、护理型床位、星级等；详情接口 `orgBaseDetail` 与 `yangLaoOrgDetail` 的页面代码还定义联系人、联系电话、面积等字段。这些只是前端字段设计，不能据此断言逐家数据存在或准确。列表页未发现 XLSX/CSV 导出入口。

## 当前决定

此源暂列为待复核官方入口，不写入本站公开 manifest，也不据其生成新机构或覆盖率数字。接口恢复后先取一页，核对 `total`、返回字段、空值和资料日期，并核实再展示边界；再决定能否纳入来源链。
