# 前台响应式优化记录（2026-11-22）

## 范围与依据

服务按地区查养老机构来源的家属。沿用 `docs/superpowers/specs/2026-11-21-eldercare-frontend-rebuild.md` 的全国入口、来源分级、只读静态数据与现有视觉令牌；本轮只处理首页、共享记录卡、在线办理标签和民政部平台详情的布局。不改数据、URL、权限、采集与发布口径。

页面任务为首页检索 → 全国目录筛选 → 扫读来源与事实 → 查看详情 → 打开官网原页或返回。当前公开 JSON 是展示值的来源；页面不把缺项、0、冲突或历史快照解释成实时服务。移动端首先保证名称、来源、操作完整可读，再提高桌面信息密度。

## 本轮调整

- 首页服务卡在右侧办事栏并排时保持两列，避免 1440px 下四个窄卡把说明挤成竖排；手机单列并降低不必要的卡片高度。
- 记录卡证据栏在窄屏按“来源 → 核对操作”纵排，长平台 ID 允许换行，链接保持至少 44px 的触控高度。
- 民政部平台长名称详情在小于 768px 时把标题与官网核对按钮纵排，避免标题只剩两三个汉字宽。
- 在线办理标签栏在极窄宽度内局部横向滚动，不推动整个页面横向滚动；保持既有键盘与 ARIA 标签语义。

## 验证与回滚

以 320、375、768、1024、1440px 和 200% 缩放检查首页、全国目录、详情与移动菜单；确认无整页横向溢出、遮挡或控制台错误，来源与返回入口可触达。类型检查、前端测试、构建和公开隔离扫描使用 `package.json` 中的真实脚本。未获得真实家属参与的结果只记为自测。

本轮前端源码仅改 `app/globals.css`、`app/page.tsx`、`components/HomeOnlineTabs.tsx`、`components/McaPublicDetailView.tsx`；回滚只撤销这些文件中的本轮布局行，不覆盖工作树中原有未提交业务与采集修改。
