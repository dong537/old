# 九站养老机构信源 B3 并行采集与查漏（2026-11-18）

## 结论与口径

按用户指定的 9 个入口分 4 路并行核查。新增的可定位逐家原件主要来自**北京养老服务网公开机构照护列表：52 页、512 条来源观察、512 个唯一 organId**。这不是 512 家已证实当前在营机构。与项目已有北京民政局 459 条星级名单及北京企查查机构线索 578 行按原始名/展示名作保守同名比对：397 条与星级名单同名，115 条未命中；后者中 53 条已有企查查线索同名，**62 条两套名称索引均未命中**，仅为人工复核优先候选，确认新增机构 0。北京列表未给可核的逐行资料截至日；首尾页与中间页来自两次会话，不能称同一时点的原子快照。

商业站养老机构网归档了 **6,363 个站点地图 URL** 和 12 个详情页样本；这是路径线索和少量商业页正文，不等于 6,363 家独立机构。URL 汉字标签与项目既有机构线索/官方来源有 **921 个严格同名 URL 候选、1,049 对来源行**，但没有从路径猜省份或确认身份。12 个样本均标“信息待核验”。本批未向网站 `public/` 添加机构行。

对北京 62 条双索引未命中候选，另有 3 条与养老机构网路径标签同名。已归档这 3 页的公开详情：可见标题与北京来源原始名称或展示名称同文，但三条地址与北京来源地址均非逐字相同（其中包括门牌层级、地名写法或楼栋写法差异）。这是待核冲突，**不能据同名确认机构身份或现时在营**。

## 证据文件与字段

- 北京：`data/private/eldercare-multisource-b3-20261118/beijing-shanghai/beijing-full/` 保存 52 页原始响应、逐页请求体/UTC 时间/状态/hash、512 行白名单对账、115 行星级名单未命中与 62 行两套名称索引未命中清单。原始响应含联系方式和身份类字段，仅保留在 Git 忽略的私有目录；白名单对账保留 organId、insId、双名称、地址、床位总数、页码/行号和原件哈希。床位总数是来源页面值，非实时空床。
- 重庆/深圳：`chongqing-shenzhen/source-observations.jsonl` 保存 1,820 个来源行、原列名/原值及原件定位；`source-manifest.json` 保存现有快照差异、缺失与 hash。深圳原表联系人电话只在私有原件/逐行文件，不进入本报告。
- 全国双入口：`national/` 保存 3 份成功 HTTP 响应原件、1 次 robots TLS 失败日志及请求元数据；没有伪造空机构列表。
- 商业三站：`commercial/` 保存养老机构网 robots/sitemap 原件、6,363 URL 清单、严格名称候选表、12 个抽样详情和 3 个北京定向详情原件；后者的字段及冲突清单在 `commercial/beijing62-overlap/`。养老信息网的旧批线索仍在 `data/private/yanglaocn-20261118/`，不重复计入本批。

各站原始字段以其页面/附件及当次响应为 Source of Truth；同名和地址只形成候选关系，不自动合并、覆盖既有官方字段或宣称在营。来源时间、资料日期、机构身份、发布许可分别记录；空值保持 null。
