## 目标与边界

按用户最新指令优先查找 `yanglaocn.com` 的机构级信息，床位差异暂不裁决。先取得可正常访问的页面及候选链接，与现有 41,955 条机构线索进行查漏和候选定位；本轮不改页面业务、不部署、不调用付费工商接口。

## 数据流与职责

- Source of Truth：来源站当次实际响应及外部搜索索引快照；前者与后者分层保存，不能互相替代。URL、检索时间、原文资料期（未知为 null）、响应状态和 SHA-256 由离线采集记录负责。
- 原始响应和候选数据写入 Git 忽略的 `data/private/yanglaocn-20261118/`，不进入 `public/`、`out/` 或前端运行时；现有网站快照与本地可部署包保持原样。
- 访问 agent 独占该站正常低频访问协调；华南和其他地区 agent 并行检索外部索引，分别写自己的候选文件；主 agent 合并、去重、核对既有目录和验证输出。
- 记录接口按来源观测保存：来源 URL、证据类型（正文/搜索索引）、机构名称、原始地区、地址、设施类型/服务（能取得时）、资料日期与取得日期。未知值保留 null；电话和人员联系方式不进入公开报告。
- 同省同名、别名或同地址只形成候选关联，保留所有冲突；不自动合并机构，也不覆盖现有官方字段。

## 失败模式与回退

正常公开 GET 或正常浏览器访问；不绕验证码、登录、403 或访问控制，不枚举隐藏接口。网络工具同输入同错误最多重试一次；正文无法取得时保存真实受限状态，仍可归档外部索引线索，但计数不得列入正文成功。

采集与现有应用隔离，可撤回本轮自有私有文件和报告；不删除既有资料、不重置用户工作树。商业来源逐家字段是否能公开展示须另有依据，未核实前保持私有候选。
