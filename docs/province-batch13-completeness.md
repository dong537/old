## 范围与验收

- 只采集、清洗和核验数据；不改网站业务、公开目录或部署，不调用付费企业查询。
- 21 市均须逐市核对官方名录的地域范围、机构类型、资料期、原件行数及缺失县区。城市有若干观察、名称或企业，不等于城市名录完整。
- “完整名录快照”和“当前在营已核”分别验收。前者须有官方全市范围声明或同期全县区可核覆盖及明确排除项；后者须有资料期明确的状态证据/变更链。不得由网页发布日期或抓取日推断资料期、在营或完整。
- 每条新增观察须保留原文、来源 URL、附件 URL（如有）、原件路径和 SHA-256、抓取时间、物理行/单元格/正文定位。专项名单、历史资料、状态事件单列，不与全量在营名录混算。
- 完成结论须覆盖 21 市全部范围；未验证项保持未完成，不能以采集数量或构建通过替代。

## 权威源与数据流

官方原件 → 各分区独立来源包（research-batch13/east、pearl、west-north、province）→ 原件/定位/范围核验 → 新版私有来源观察与逐字段审核产物 → 城市覆盖矩阵。第十二批 v5/v8 为只读基线，不覆盖。机构实体、机构服务点与企业登记主体继续分离。

本轮使用独立文件式研究包，不新增数据库、API、生产运行时或 UI。网络失败、验证码、审核开放和未取得附件均记实；不绕过认证/审核，不用搜索摘要代替官方明细。回滚只切回既有版本路径。
