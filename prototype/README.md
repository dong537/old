# dist(1) 本机复刻

页面、组件、样式及演示逻辑完整复制自用户提供的 `dist(1)`；`source-manifest.json` 记录原文件的 SHA-256，测试会逐项核对。原说明保存在 `REFERENCE_README.md`。

在项目根目录执行 `npm run dev` 或 `npm run dev:prototype`，访问 `http://127.0.0.1:3100/guangzhou`。复用根目录依赖，无须在这里重复安装。使用 `PORT` 可调整端口；启动器固定绑定本机地址。

这是原型演示：机构、服务商、价格、空床、预约、认领和后台流程均沿用原型示例。状态仅保存在进程内，重启重置；后台没有真实鉴权。不要提交真实个人资料或对外部署。本机配置拒绝生产构建与生产启动，所有路由有 `noindex, nofollow`，robots 禁止抓取。除这类非视觉运行边界，原始界面源码不作改写。

真实的 235 家广州机构资料、公开构建及私有工商预览仍在根应用；详情见根目录 README。
